## 0. 結論（先に）

1. **指標 (ii) の合計はレーザーの相関の崩れ（成分 3）と共通点の揺れ（成分 2）でほぼ決まる。** F_liu20 ポート 31（1268 m）の Liu 型の名目は 1 s で 107.6 ± 0.9 mrad（成分 1 = 6.8、2 = 57.0、3 = 90.3、4 = 13.0）、30 s（= t_cal）で 121.0 ± 6.1 mrad（49.0 / 59.9 / 90.3 / 13.3）[sim]。1 s の P2・P3・P4・P6・P8（2 トーン）の合計は 107.3–107.6 mrad で、seed のばらつきより大きな差はない（`explore.differs`）。
2. **合計を下げたのは P5（in-band の遅い層）だけ**: 30 s で 121.0 ± 6.1 → 93.6 ± 0.2 mrad。成分 1 は 49 → 10.8、成分 2 は 60 → 18.4（F_wg6 では 111 ± 6.3 → 86.8 ± 0.2）。P5 と融合したもの（P2 + P5 は 93.5、P3 + P5 は 94.4、P1 を遅い層にした上限は 93.4）は P5 と差がない。残りは成分 3 の 90 mrad で、**レーザーの線幅の問題**である（D78）。
3. **30 s の成分 1（49 mrad）は E41（直交偏光の PM の probe が見る複屈折のドリフト）**。1 s・3 s・10 s・30 s で 6.8・7.0・13.5・49 と実行の長さとともに増える（D92-4 の 49.7 と一致）。**同偏光の 2 トーンの probe（P8）は 30 s でも成分 1 = 6.8 mrad**。後方散乱は ±675 MHz で OPO の狭いモードの外に出るので、迷光は 1.5 × 10⁻⁸ /モード（F_liu20）にとどまる。導波路（F_wg6）ではモードが広く 1.0 × 10⁻³ となり、上限を超える。
4. **周波数をずらした probe はポートごとの静的なオフセット Θ_k,static = π·frac(Δν·Δτ_k) を残す**（F_wg6・F_bor6 の 80 MHz / 1 THz で 1.04 rad、F_liu20・F_wg100 では 0）。Δν を f_rep/(N_b + n_guard) の整数倍の格子に置くか、ポートごとに較正する必要がある（P8 の `tt_on_grid` と同じ条件）。
5. **WDM の probe（P3・P4）は迷光を 10⁻¹³ /モードまで消すが、η_k を 0.632 → 0.446 に下げる**（WDM 2 個 × 0.8 dB）。名目の 1 nW の Liu の probe の迷光は 8.2 × 10⁻⁶（T17 の上限 5.8 × 10⁻⁴ の 1/70）なので、F_* では WDM による迷光の利得より損失の方が大きい。
6. **P2 の窓は周期 ≤ 1 ms なら成分 1 を約 2 mrad 悪くするだけで、窓の平均の迷光を 5–1000 倍下げる**（最悪のスロットは変わらない）。10 ms では保持中のドリフトで 41–63 mrad となり、スリップも出る。**P8 の間欠ループは単独では成り立たない**（280 mrad、スリップ 961 回）。
7. **制御器が成分 1 を決める**: fpga_generic（16 bit）6.8、Moku:Delta 13.9、DSC1 37.9 mrad（DAC の LSB によるリミットサイクル）。Ref D で較正した音響は γ = 0 で 30.8 mrad、γ = 1 で 312 mrad（**3 kHz より上は外挿**）。
8. **BoTorch は f_u を約 450–590 Hz にする**（R(f_u) = 1 + 3πf_uΔτ が下がるため）。ただし改善は 0.1–0.8 mrad で seed のばらつきより小さく、制御器の調整では指標 (ii) は直らない。
9. **推奨**: D14 は Liu 型 ＋ P5、D12 は LO 配送のロックは不要、D49 は 0.5 dB の規則で σ_t ≈ 44 mrad とし分散の半分をレーザーへ、D13 は 32 ポート同時は不要（§7）。

## 5. BoTorch（手順 5、`botorch_traces.png`）

- 目的は 3 seed の平均の (ii)（平均を引いた値、3 s）。制約は「ロックを保つ」と「|S|² の最大 ≤ 4（|S| ≤ 2）」。

## 6. アーチファクトの検査（`convergence.json`、3 s、seed 1）

- **チャンク**: base・P2・P3・P5・P8 のすべてでビット単位で同じ。
- **f_sim × 2**: (ii) の合計は +1.4 mrad（1.3 %、P5 は −0.5）で、全方式で同じ向き。seed のばらつき（±3.2）以下で、比較では打ち消す。時間ループと台帳への分け方は f_N で動くが、和は保たれる。
- 指標 (i) は 1 seed では雑音の実現値の違い（seed のばらつき ±0.26 rad）で動くので、この検査には使えない。
- **実行の長さ**: 成分 1 は 1 / 3 / 10 / 30 s で 6.8 / 7.0 / 13.5 / 49（E41）。成分 2 は台帳の行のおかげで長さによらず 57–60。成分 3 は不変。結論（§0）は 30 s の値で述べた。
- **seed**: 10 seed で、差は `differs` でだけ主張した。

## 7. 推奨

- **D14（LOCK_TOPOLOGY）**: Liu 型（逆向き・直交偏光・PZT ＋ TEC）＋ P5 の in-band の遅い層（較正フレーム 20 %、ポンプを切る）。根拠は 30 s で 121 → 93.6 mrad（成分 1・2 を消す、§4）、迷光と η はほぼ不変。LiuPD-A・B は (ii) を変えず、(i) と絶対角のために選ぶ。L-A-seed は成り立たない。OPO のプリセットでは、同偏光の 2 トーンの probe（P8）が E41 を消す第 2 の候補。
- **D12（LO 配送のロック）**: GBS には不要（(ii) は ±0.1 mrad で同じ）。BHD でポートごとに (i) を測るときだけ選択肢として使う（(i) 0.86 → 0.07 rad）。使うときは km の LO ファイバのドリフト（約 5 rad/s）に対して ±10 rad の PZT では足りず、TEC の段が要る [AE]。
- **D49（σ_t の配分）**: σ_t は「位相雑音による損失 ≤ 0.5 dB」すなわち V₊σ_t² ≤ (10^{0.05} − 1)V₋ で決める。F_liu20 の名目（V₋ = 0.195、V₊ = 12.0）で σ_t = 44.5 mrad。分散の半分をレーザー（制御で直せない）に配り σ₃ ≤ 31.5 mrad、すなわち Δν ≤ σ₃²/(2πRΔτ) = 24 Hz（ポート 31、現状 201 Hz、8 倍狭くする）。残りを等分し σ₁・σ₂・σ₄ ≤ 18 mrad。P5 は 10.8 / 18.4 / 12.9 でこれを満たす。η が良くなると σ_t は小さくなる（η = 0.9 で 21.5 mrad、Δν ≤ 5.7 Hz）[AE]。
- **D13（32 ポートを同時に扱うか）**: 不要。成分 3 は Δτ だけで決まり（組と単独で一致）、ρ の効果は小さく、線形のモデルなので Cov(Θ_j, Θ_k) = ½(Var Θ_j + Var Θ_k − Var(Θ_j − Θ_k)) により、組の実行から全ポートの共分散を組める。32 ポートは約 57 µs/サンプル（D80）で、30 s が 28 分、10 seed の分解で約 24 h かかり、実行はできるが必要ない。

## 9. ベンチ実験（上位 2 方式、DX1・914/915B・DSC1・PDB450C・Moku:Delta）

1. **P5 の 2 層ロック**:
   - Ref D の 2 腕のファイバ干渉計で、速い層は DSC1（または Moku）＋ PDB450C の DC の縞のロックで 915B を駆動する。
   - 遅い層は同じ経路を通る弱い in-band の光（DX1 から減衰・AOM で較正の窓に切り出す）を PDB450C の低パワーの出力で T_int = 50 ms 積分し、Moku:Delta の PID の制御行列で速い誤差に設定値として足す。
   - 代理信号の偏りを意図して入れ（PM の直交偏光の区間・腕のヒータ）、独立なモニタの干渉計で 30 s の残差が f_c ≈ 2 Hz 以下で消えることと、T_int に対する計数（ショット）雑音を測る。
   - 予想: 偏りの成分は (f/f_c) の程度まで下がる（§4 の 49 → 11 mrad の縮小）。
2. **P7 と、P8 の根拠となる E41 の測定**:
   - (a) Moku:Delta の FRA（MiM）で 915B のループをロックしたまま同定する。主モードの近く（15–35 kHz）を細かく掃引し、5.3 / 10 / 25 / 40 kHz のモードと利得余裕を決める（D96-8 の当てはめが一意でない問題を解き、BoTorch の上限を与える）。
   - (b) PM のスプール（100 m–1 km）で、逆向きの probe の直交偏光と同偏光のそれぞれについて、スプールの温度（ヒータ・TEC）に対する偏りを測り、K_T·L（約 2 rad/(m·K)）を確かめる。
   - 2 トーン自体には ±675 MHz の EOM が要る（手持ちにない、UNVERIFIED）。

## 10. 不具合と設定の落とし穴

1. **`lock/dual_band_slow` が制御器の入力段 `in_bw1` を飛ばしていた**（設定値の和を adc1 に直接入れていた）。DSC1 では port k だけ 120 kHz の極が抜け、`chk.lock_stability` とずれていた。→ in_bw1 に入れるように直した（ctrl_in_pole_hz = inf では同じ）。テスト `test_slow_layer_keeps_the_controller_input_pole`。
2. **P5 はどのゲートの上書きとも組めなかった**（D96-9）。→ dual_band_slow に `overrides: [gate/*]` を宣言し、結合の上書き `lock/dual_band_slow_gate_wire` を作った（順序: ゲート → P5 → 点 → wire）。テスト ＋ manifest。
3. **`presets/locks/L-LOdeliv` の指標 (i) の設定値**: LO のロックは cos の零点（±π/2）に固定するので LO を π/2 回す。F_common の (i) の設定値 −π/2 のままでは、直交位相の折り返しの境界で評価され、(i) ≈ 1.5 rad と崩れていた。→ 設定値 0（mod π）。テスト `test_lo_delivery_lock_metric_i_set_point`。(ii) は不変。
4. 落とし穴（記録のみ）:
   - 周波数をずらした probe の格子の条件（§0-4）。
   - 3 s までの BoTorch には 30 s の E41 が見えない。
   - P7 の 25 点の格子は高い Q のモードをまたぐ。
   - pumped の P5 は F-1 の偏りがモデルになく楽観的。
   - L-LOdeliv は ±π/2 の初期誤差（縞の頂上）から約 1 s かけて引き込むので、(i) の t_settle（5 ms）では足りない。

Open（提案）: P8 同偏光の 2 トーン ＋ P5 の融合（未実行。two_tone と dual_band_slow の合成を確認する必要がある）、成分 3 を下げる Hz 級のレーザーの選定、スプールの音響の実測（γ の決定）。
