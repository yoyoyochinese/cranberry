σ² = ∫|e^{−i2πfδ} − H_FC(f)|² h0/f² df（数値積分）: FC 3.3 MHz で zero 155.7・fc_opt 96.7 mrad（時間ループと 1 % で一致: 台帳が

- **物理:** DX1 の線幅では LO の FC そのものが squeezing を消す。要求は πh0/Δν_FC ≤ σ² なので、σ = 20 mrad には
  **Δν_FC ≥ πh0/σ² ≈ 200 MHz（実質 FC なし）**、かつ遅延差 |δτ| ≤ σ²/(2π²h0) ≈ **0.8 ns（ファイバ 16 cm）**。
- **数値の注意（§1.4）:** FC 33 MHz と FC なしの時間ループの値は連続の式より 12–45 mrad 高い（時間ループの離散化の床）。
  物理の見積もりは「FC なし・遅延ゼロ」で非レーザーの部分（アブレーションで DX1 を切ると 12.3 mrad）だけの **≈ 12–15 mrad**、
  「FC 33 MHz・fc_opt」で √(30.6² + 12.3²) ≈ **33 mrad**。ただし FC を外すと LO の過剰雑音（DX1 の RIN・測定側帯の位相雑音）が BHD に入り、
  これはモデルにない（UNVERIFIED、測って決める）。
- 100 m は音響で EOM2 が飽和（上記）。DX1 の救済は 10 m 以下で評価した。

### 1.4 時間ループの離散化の床（DX1、FC が広いとき）— 数値の人工物

FC なし・遅延ゼロ（10 m、音響なし、seed 1、30 ms）: f_sim 20 / 40 / 80 MHz で σ_total 56.3 / 54.9 / 37.9 mrad（物理の期待は数 mrad）。
遅延のずれ −30 … +30 ns の掃引（`sq_lo_offset_s` を直接）では 0 ns が最小（132 / 96 / 56 / 87 / 123 mrad）で、56 mrad の床は遅延差によらない。
原因（推定）: DX1 の位相は f_sim = 20 MHz の 1 サンプルあたり σ_step² = 2πΔν/f_sim = 0.025 rad² 拡散し、ビームごとの分数遅延の
線形補間（squeezed 光はポンプ経由で 2 回、LO は 1 回）の誤差が a(1 − a)σ_step² の程度（最大 79 mrad）残る。
f_N より上は台帳が「連続 − 離散」の差を足すが、差が負（離散のほうが大きい）のときは 0 に切られる（DECISIONS Open「台帳の符号付きの行」、D66-1）。
FC 3.3 MHz では FC の項が大きく差が正なので一致する（§1.3）。**影響: DX1 ＋ 広い FC／FC なしの時間ループの値は上限側（悲観側）。**
Koheras 代用（h0 64）では σ_step² が 400 倍小さく、この床は ≤ 4 mrad。D99 案（§7）。

### 2.1 アブレーション（10 m、42 トグル、量は時間ループと台帳の位相雑音 σ_phase、1 MHz のディザは除く）

基準 2.10 ± 0.07 mrad、効いた効果だけ on で 2.02 ± 0.07。効いた効果: `path.phase.phase`（経路の位相雑音全体）−1.86（→ 0.20）、

位相の予算を決めるのは 1 MHz のディザ（χ = J0(2m)、σ_dither = 55.5 mrad 相当）で、時間ループの 2–3 mrad の 25 倍。

2. **周波数をずらしたプローブはベンチの長さで静的な偏り 2πΔf·Δτ を持つ。** F_common の格子（ポートの長さに合わせた Δν）から外れたベンチの長さでは、
   偏りが 0.17–1.44 rad になり L に対して不規則に変わる（`c_metric_ii_static_bias.png`）。±π/2 の近くでは指標の折り返しで統計が壊れる
   （WDM 1 THz・P3 の 10 m: 1.41–1.44 rad、std 99–264 ± 110–260 mrad、分解の線形性 0.72–4.0）。**ベンチでは設定値（または LO の位相）で静的な偏りを
   引く較正が必須**で、指標 (i) の R′− の値（偏りを含む）はそのままでは使えない。プリセットには偏りを吸収する選択肢がない（§7 の提案）。
3. **P3 のチョッパ（6 kHz、プローブのデューティ 50 %）は音響ありで残差を 1.3–1.4 倍にする**（21.3 vs 15.9、120 vs 87、差は広がりより大きい）。
   プローブが半分の時間しか当たらず、誤差の低域通過（< f_ch）で帯域が下がるため。P3 の利点（迷光の時間分離）はこの指標には出ない（迷光の表は D88）。
4. **P8（直交偏光の 2 トーン）は 1 m と 100 m で悪い**（41.6、145.5）。格子から外れた長さで E が大きく、縞の振幅 cos E が下がってループ利得が落ちる（D94-5）。
   同偏光の変種は群複屈折が消えて偏りが小さいが、31.6 m でスリップが多い。
5. **実験室の音響はポートと LO のファイバの両方に効く。** 指標 (ii) の std は 1 → 100 m で 16 → 87 mrad（≈ L^0.37）。ベンチの測定量である指標 (i) は
   42 → 288 mrad で、指標 (ii) よりずっと大きい: **LO の配送ファイバ（LO1）はロックされていない**（D12 の LO 配送のロックの問題がベンチでそのまま出る）。
   1 ポートのパルスのベンチで BHD を使うには、Ref A の lock 2 のような BHD でのプローブ–LO のロックが要る。
6. **制御器の量子化の床。** 静かな条件で DSC1 は 44–51 mrad、Moku は 16–22 mrad で、音響ありの DSC1（30 mrad、1 m）より悪い。
   12 bit の DAC の LSB は F_common の PZT の利得で 15.9 mrad（wire_F のヘッダ）。雑音のない I 制御のループでは量子化器がディザされず、
   DAC が ±数 LSB のリミットサイクルを作る（音響があると雑音がディザになって床が下がる）。P3 の誤差の低域通過はこれを抑える（DSC1 静か 13.3–21.5 mrad）。
   **対策: DSC1 と 914 の間に減衰器（例 −20 dB）を入れて LSB を 1.6 mrad に**（PZT の使用率は 0.09 なので 10 倍しても範囲内。長時間のドリフトは TEC へ）。

## 6. 推奨: 次のベンチ実験（順位付き）

順位は「手元の装置で組めるか（費用）」「squeezing／位相の安定化について新しく分かること」「モデルの不確かさを減らすか」の順で付けた。

**1 位: refD_lab の DSC1 のゲインの変更と、ロックしたままの 915B の伝達関数の測定（追加の部品なし、最も安い）**
- 設定: DSC1 の P = 1.60×10⁻³、I = 9.46×10⁻⁴、D = 8.60×10⁻³（DSC1 の入力値、現行 D53 は 2.41e-4 / 1.406e-3 / 1.108e-2）。設定値は現行どおり。
- 期待: 5.4 kHz のサーボの山 |S|² 12.4–13.9 → 3.6–3.75（−5.4 dB）、利得余裕 2.9–3.3 → 6.9–7.6 dB、f_u 2.2 → 1.4 kHz、
  位相誤差（0–500 kHz）41–42 → 42.7–43.0 mrad（+4 %）。副モードが Q 15・r 0.11 でも Q 5・r 0.34 でも成り立つ。
- 最初に測るもの: (i) **915B の伝達関数**: Moku:Delta の FRA の出力を PDB450C の出力に加算して DSC1 に入れ、1–50 kHz の 41 点（4–7 kHz に
  20 点を追加）、0.1 V、1 点 25 ms（掃引 約 1 s、5 回平均）。Ĥ_915B = L̂/L_known で二つの解が z 値 1.2–1.6 対 23–33 で区別できる（§4.3）。
  (ii) **DSC1 の出力のスペクトル**（DAC のリミットサイクル、25・40 kHz の山の量子化の仮定、D89-4・D96-8）。(iii) **長い記録**（≥ 30 s: 1–100 Hz、スリップ）。
- 次の一手（安い）: 腕の差 ΔL ≈ 9 m（915B のコイル 8.4 m）を反対の腕に PM ファイバ 8.4 m を足して ≤ 0.5 m にする。DX1 の遅延の項（31 mrad、
  4π²τ²h0 ∝ ΔL²）は 0.1 mrad に下がり、残りは音響と温度の ≈ 27 mrad（ただしファイバが増える分の音響は γ = 1 なら増える。測って確かめる）。

**2 位: Ref A 型の CW 導波路 OPA ＋ DX1、LO のフィルタキャビティなし、遅延を合わせた ≤ 10 m のファイバ（squeezing を出す最初の実験）**
- 設定: LO は DX1 から直接（FC なし、または Δν_FC ≥ 200 MHz）、squeezed と LO の光源からの遅延差 |δτ| ≤ 0.8 ns（ファイバで 16 cm 以内に切り揃える）、
  ファイバ ≤ 10 m（31.6 m 以上で実験室の音響が lock 2 の EOM の ±0.45 rad を超える）、lock 2（BHD のプローブ–LO のビート → EOM）は Moku:Delta
  （14 bit、遅延 ≤ 0.21 µs）。EOM の駆動は ±π 以上（Moku の ±0.5 V なら 10 Vpp の増幅器、または DSC1 の ±4 V、+0.3–4 mrad）。ストレッチャへの肩代わりは 915B。
- 期待: 位相雑音 ≈ 12–15 mrad（物理の見積もり、時間ループは上限 57.6 mrad、§1.4）、R′− ≈ −8.3 〜 −8.5 dB（η_BHD 0.88、V− −9.0 dB、V+ +20.4 dB から
  V′ = V− cos²σ + V+ sin²σ）。FC 33 MHz を残すなら ≈ 33 mrad で −6.1 dB。今の FC 3.3 MHz のままなら DX1 では squeezing は出ない（+5.8 dB）。
- 最初に測るもの: **DX1 の測定側帯（数 MHz–数百 MHz）での過剰雑音**（FC を外すと LO の過剰雑音が BHD に入る。モデルにない、UNVERIFIED）:
  PDB450C の平衡で LO だけを入れ、ショット雑音のパワー依存の直線性を確かめる。次に **遅延差の測定**（変調した LO と squeezed 経路の位相差の周波数依存）。
- 足りない部品: 繊維結合の PPLN 導波路（SHG ＋ OPA）、EDFA、EOM 2 個、1 MHz の周波数シフタ（AOM）。

**3 位: Ref C 型 CW OPO ＋ 雑音ロック（最も頑健、最も高い）**
- 位相雑音 2.1–3.5 mrad（1–100 m、どの制御器でも、DSC1 でも）、DX1 で +4.1 mrad、予算は 1 MHz のディザ（55.5 mrad）。squeezing は
  30 MHz で −5.6 dB（OPO の η と側帯で決まり、ファイバ長にも制御器にもほぼよらない）。DSC1 はそのまま使える（ディザと復調は外付け）。
- 足りない部品: OPO（単一共振 ppKTP）、SHG、1 MHz のディザと復調器。費用と組み立ての手間が最大。

**4 位: パルス導波路 OPA の 1 ポート（pulsed_wg_1port）**
- 手元にパルス光源がない。ベンチの BHD の量（指標 (i)）は LO の配送ファイバがロックされていないので音響ありで 42–288 mrad（1–100 m）、
  R′− −4.3 → +0.2 dB。Liu 型の代理ロックだけでは足りず、BHD でのプローブ–LO のロックが要る。周波数をずらしたプローブ（ヘテロダイン・WDM・P3）は
  静的な偏り 2πΔf·Δτ を較正で引く必要があり、動的な残差は Liu と同じ。P3 のチョッパは 1.3–1.4 倍悪い。P5 の 2 層ロック（暫定）は
  指標 (ii) の σ_total を 10 m で 80.5 → 49.7 mrad にするが、BHD の量は変えない。DSC1 を使うなら 914 の前に −20 dB の減衰器。
- 軸 2（GBS）の準備として価値はあるが、軸 1 の次の実験としては最後。

## 7. DECISIONS への提案（D99 案、調整役が書く）

### D99 Phase 6 軸 1 の探索の結果（`notes/findings_axis1.md`）
- 決定（案）:
  1. I-7 を実装: `ident/wire_F` の `ident.exc` は `rate_div: offline.params.pid_rate_div`（`controller/dsc1` で 2）、記録の間引きは
     pid_rate_div の倍数で ≥ 2（fpga・Moku は従来の 2）。テスト `test_F_wire_F_runs_at_the_controller_rate`（dsc1・fpga）。
  2. (d) refD_lab の DSC1 の推奨ゲイン（BoTorch、制約 max |S|² ≤ 4 = M_s ≤ 2、副モードの 2 解で頑健）: P 1.60e-3、I 9.46e-4、D 8.60e-3。
     |S|² 12.4 → 3.6、利得余裕 3.3 → 7.6 dB、位相誤差 +4 %。プリセットの値は変えない（D34、D53 は記録のまま）。ベンチで試す点として。
  3. ロックしたままの同定（`ident/wire_refD` ＋ stepped sine、1 s）で 915B の副モードの 2 解（D96-8）を区別できる（z 1.2–1.6 対 23–33）。
     ベンチの手順は Moku:Delta の FRA を DSC1 の入力の前で加算。41 点の粗い格子では −180° の交差を取り逃がすので 4–7 kHz を細かく。
  4. (a) DX1 では Ref A の LO のフィルタキャビティ（3.3 MHz）が squeezing を消す（√(πh0/Δν_FC) = 156 mrad）。要求: Δν_FC ≥ πh0/σ²
     （σ = 20 mrad で 200 MHz）、遅延差 ≤ σ²/(2π²h0)（0.8 ns）。lock 2 の EOM の ±0.45 rad は実験室の音響で L ≥ 31.6 m なら飽和する。
  5. 数値の注意: DX1 ＋ 広い FC／FC なしの refA の時間ループは 1 サンプルあたりの位相拡散（2πΔν/f_sim = 0.025 rad²）と分数遅延の補間で
     ≈ 40–56 mrad の床を持ち、台帳の「連続 − 離散」の行が負になると 0 に切られる（Open「台帳の符号付きの行」）。その点の値は上限。
     提案: 台帳が負の差を切ったときに CHK `ledger_clamped`（値と行の名前）を出す。または DX1 の線幅では f_sim を上げる。
  6. (c) 周波数をずらしたプローブ（`probe/freq_*`、`detect_heterodyne`、`two_tone`）はポートの格子から外れた長さで静的な偏り 2πΔf·Δτ を持ち、
     ±π/2 の近くで指標の折り返しにより統計が壊れる（WDM 1 THz・P3 の 10 m）。提案: 偏りを設定値で吸収する選択肢
     （Ref A の `pr_bhd_static_absorb` と同じ形の新しい上書き用の設定、既存は変えない）。
  7. (c) DSC1 の 12 bit の DAC は F_common の PZT の利得（8.125 rad/V）で LSB 15.9 mrad、雑音のない条件で I ループのリミットサイクルが
     指標 (ii) に 44–51 mrad の床を作る（Moku 16–22、fpga 6.8）。ベンチでは 914 の前に減衰器（−20 dB）。
  8. (c) 1 ポートのベンチでは LO の配送ファイバがロックされず、BHD の量（指標 (i)）が音響ありで 42–288 mrad（1–100 m）。D12 の
     LO 配送のロックはベンチでは必須。
  9. P5（D98 の名目、暫定）: 1 ポート・2 s・音響ありで指標 (ii) の σ_total 80.5 → 49.7 mrad（10 m）、116 → 97 mrad（100 m）。
     共通点のドリフト（静的な平均のばらつきと台帳の窓の行）を消す。BHD の量は変えない。`seed_psa`・`cal_slot` のレビューの後に確定。
  10. 次のベンチ実験の順位: (1) refD_lab のゲイン変更 ＋ 915B の同定 ＋ DSC1 の出力のスペクトル ＋ 長い記録、(2) Ref A 型 CW 導波路 OPA ＋ DX1、
      FC なし・遅延 ≤ 0.8 ns・≤ 10 m、(3) Ref C 型 OPO、(4) パルスの 1 ポート。
