## 0. 結論

1. **GBS の系（軸 2）では、指標 (ii) の残りはレーザーの線幅で決まる。** F_liu20 ポート 31（1268 m）で、成分 3（レーザーの相関の崩れ）は
   90 mrad で、σ² = R·2π²h0Δτ_k に 2 % で合う。どのロックも白色 FM を消さない（D78-1）。
2. **ロックの方式で合計を下げたのは P5（in-band の遅い層）だけ**: 30 s で 121.0 ± 6.1 → 93.6 ± 0.2 mrad（F_wg6 は 111 → 86.8）。
   P5 は成分 1（E41 の偏りを含む、49 → 10.8）と成分 2（共通点、60 → 18.4）を消す。P5 と融合したもの（P2・P3・P1 を遅い層に）は P5 と差がない。
3. **30 s の成分 1 は E41（直交偏光の probe が見る複屈折のドリフト）。** 同偏光の 2 トーン（P8）は単独でこれを消す（49 → 6.8）が、
   後方散乱が OPO の狭いモードの外に出る場合だけ迷光が許される（F_liu20 で 1.5e-8、導波路では 1.0e-3 で上限超え）。
4. **ベンチ（軸 1）では、今の refD_lab のゲインが不安定の縁にある。** BoTorch のゲイン（P 1.60e-3、I 9.46e-4、D 8.60e-3）で
   |S|² 12.4 → 3.6、利得余裕 3.3 → 7.6 dB、位相誤差は +4 %。915B の副モードの 2 解（D96-8）のどちらでも頑健で、ロックしたままの同定で 2 解を区別できる。
5. **DX1 の線幅は狭帯域のフィルタキャビティと腕の長さの差に厳しい。** Ref A の 3.3 MHz の FC では squeezing が消える（約 190 mrad）。
   要求は Δν_FC ≥ πh0/σ²（200 MHz）、遅延差 ≤ 0.8 ns。refD_lab では ΔL ≈ 9 m を通る白色 FM（31 mrad）が最大の項で、PM 8.4 m で合わせれば消える。
6. **周波数をずらした probe（WDM・P3・P4・P6・P8）は、ポートの格子から外れた長さで静的なオフセット π·frac(Δν·Δτ_k) を残す**（0.17–1.44 rad）。
   Δν を格子に置くか、ポートごとに較正する。WDM の probe は η_k を 0.632 → 0.446 に下げ、F_* では迷光の利得より損失が大きい。
7. **制御器の量子化が床を作る。** DSC1 の 12 bit の DAC は LSB 15.9 mrad のリミットサイクルで、成分 1 を 38 mrad（軸 2）、
   1 ポートのベンチで 44–51 mrad の床にする。914 の前の −20 dB の減衰器で直る。
8. **BoTorch の制御器の調整は GBS の系では効かない**（0.1–0.8 mrad、seed のばらつき以下）。効くのは系の構成（P5、同偏光の probe、レーザー）である。

## 3. 物理の説明（軸をまたぐ要点）

- **成分 3 と線幅:** 2 つの経路の遅延差 Δτ の間にレーザーの位相が拡散する。ロックは probe の経路の位相を測るので、squeezed 光と LO の
  発光時刻の差に由来する拡散は消せない。軸 1 の DX1 ＋ FC、refD_lab の ΔL、軸 2 の 1268 m のポートは同じ機構である（D78）。
- **成分 2 と遅い層:** 共通点の短いファイバのドリフトは probe の分岐の外にあり、1/t_cal–1/T_rec の帯域ではどの速いロックも見ない。
  真の経路（シード → SNSPD）を測る P5 だけが f_c ≈ 2 Hz 以下でこれを消す。
- **E41:** 直交偏光の probe は複屈折の温度ドリフトを位相として読む。実行が長いほど増える（1 / 3 / 10 / 30 s で 6.8 / 7.0 / 13.5 / 49 mrad）。
  同偏光にすると消え、in-band の遅い層でも消える。
- **静的なオフセット:** 周波数 Δν だけずれた probe は長さ L_k で 2πΔν·Δτ_k の位相を持ち、Δτ_k の格子が Δν に合わない限りポートごとに残る。
- **制御器:** 速い制御器の利得や f_u は |S| を変えるが、上の 3 つはループの外か probe に見えない量なので、調整では直らない。

## 4. 数値の検査（刻み・チャンク・seed）

- **チャンク:** 軸 1 の 12 点と軸 2 の 5 方式で、チャンクの大きさを変えてもビット単位で同じ。
- **刻み（f_sim × 2）:** 軸 2 は (ii) の合計 +1.4 mrad（1.3 %、全方式で同じ向き）で比較では打ち消す。軸 1 は大半が 0.1 mrad 以下。
  例外は 2 つで、どちらも結論は変わらない:
  - DX1 で FC が広いかないときの時間ループに 40–56 mrad の床（D99-5）。その点の値は上限。
  - refD_lab の std は f_N までの帯域の値（+19 %）。ゲインの比較は 50 kHz より下だけで、影響しない。
- **seed:** すべて 10 seed（共通の乱数）。差は `explore.differs`（|Δ| > σ_a + σ_b）を満たすものだけを主張した。
- **実行の長さ:** E41 は 30 s でしか見えないので、軸 2 の見出しと P5 系は 30 s（= t_cal）で評価した。3 s の BoTorch の目的には E41 が入らない。

## 5. 推奨（D14・D12・D49・D13）

- **D14（LOCK_TOPOLOGY）:** Liu 型（逆向き・直交偏光・PZT ＋ TEC）＋ P5 の in-band の遅い層（較正フレーム 20 %、ポンプを切る）。
  根拠: 30 s で 121 → 93.6 mrad、迷光と η はほぼ不変（§2）。OPO のプリセットでは、同偏光の 2 トーン（P8）が第 2 の候補。
  LiuPD-A・B は (ii) を変えないので、(i) と絶対角のために選ぶ。L-A-seed は成り立たない。
- **D12（LO 配送のロック）:** GBS には不要（(ii) は ±0.1 mrad で同じ）。BHD で測るベンチとポートごとの特性評価では必須
  （軸 1 の 1 ポートで 42–288 mrad、軸 2 で (i) 0.86 → 0.07 rad）。km の LO ファイバでは TEC の段が要る [AE]。
- **D49（σ_t の配分）:** 「位相雑音による損失 ≤ 0.5 dB」すなわち V₊σ_t² ≤ 0.122·V₋ で σ_t を決める（F_liu20 の名目で 44.5 mrad）。
  分散の半分をレーザーに配り σ₃ ≤ 31.5 mrad（ポート 31 で Δν ≤ 24 Hz、今の 201 Hz の 1/8）。残りを等分して σ₁・σ₂・σ₄ ≤ 18 mrad。
  P5 は 10.8 / 18.4 / 12.9 で満たし、残るのはレーザーだけである。η = 0.9 なら σ_t = 21.5 mrad、Δν ≤ 5.7 Hz [AE]。
- **D13（32 ポートの同時の実行）:** 不要。成分 3 は Δτ だけで決まり、相関 ρ の効果は小さい。モデルが線形なので、2 ポートの組から全ポートの共分散を組める。

## 7. ベンチ実験（上位 2 方式を今の機材で試す）

機材: DX1・914/915B・DSC1・PDB450C・Moku:Delta。どれも Ref D の 2 腕のファイバ干渉計の上で行う。

1. **準備（P7 ＋ 軸 1 の 1 位）:** DSC1 を推奨ゲインに変える。Moku:Delta の FRA の出力を DSC1 の入力の前で PDB450C の出力に足し、
   ロックしたまま 915B を同定する（1–50 kHz、0.1 V。4–7 kHz と 15–35 kHz は細かく）。副モードの解を決め、BoTorch の上限を与える。
   同時に DSC1 の出力のスペクトルと 30 s 以上の記録を取り、ΔL の補償（PM 8.4 m）の前後を比べる。
2. **P5 の 2 層ロック:** 速い層は今の DC の縞のロック。遅い層は同じ経路を通る弱い in-band の光（DX1 から減衰と AOM で較正の窓に切り出す）を
   T_int = 50 ms 積分し、Moku:Delta の制御行列で速い誤差に設定値として足す。PM の直交偏光の区間や腕のヒータで代理信号に偏りを入れ、
   独立なモニタの干渉計で 30 s の残差が f_c ≈ 2 Hz 以下で消えることと、T_int に対する計数雑音を測る。予想: 偏りの成分は 49 → 11 mrad の程度に縮む。
3. **P8 の根拠の測定（E41）:** PM のスプール（100 m–1 km）で、逆向きの probe を直交偏光と同偏光にしたときの、スプールの温度に対する偏りを測る
   （K_T·L ≈ 2 rad/(m·K) を確かめる）。2 トーンそのものには ±675 MHz の EOM が要り、手持ちにない（UNVERIFIED）。

## 8. 残っていること

- P8 同偏光の 2 トーン ＋ P5 の融合（未実行）、成分 3 を下げる Hz 級のレーザーの選定、スプールの音響の結合 γ の実測（D100）。
- 台帳が負の差を切ったときの CHK `ledger_clamped`、周波数をずらした probe の静的なオフセットを吸収する上書き（D99-5・D99-6）。
- 検出方式の設定とゲートの設定を合わせる設定、two_pole の f_N より上の二重計上、LO ストレッチャーの 2π リセット。
- UNVERIFIED: Moku のロック中のグリッチのない位相変更、ポンプのゲートのハードウェア、±675 MHz の EOM。
- 入手していない補足資料: Aurora の SI、Jiuzhang 2.0 の SM、Pittaluga の SI。
