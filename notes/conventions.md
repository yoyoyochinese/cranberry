# 規約（conventions）

全ノート・全モジュールはこの規約に従う。規約と異なる文献の式を使うときは、ノートに「文献の規約 → この規約」の変換を書くこと。
記号の定義は英語、説明は日本語（DECISIONS D19）。
改訂: 2026-10-28 初版（D33）、2026-10-31 Phase 1 の提案を反映（D47・D49）。

## 1. 単位と記号

- 内部は SI 単位。ただし量子演算子は ħ = 1 の無次元の直交位相（quadrature）で書く。
- t: lab time [s]。T: GNLSE の遅延時間 T = t − β1 z [s]。z: 伝搬距離 [m]。
- f: 遅い雑音（位相雑音・制御）の Fourier 周波数 [Hz]。
- Ω: 光のサイドバンド周波数（キャリア ω0 からのずれ）[rad/s]。ESA の中心周波数などは f_s = Ω/2π [Hz] で書く。
- ω0: キャリア角周波数 [rad/s]、λ0 = 2πc/ω0。
- 文献の記号がこの規約の記号と衝突するときは（例: Ref B の Ω・γ・L）、ノートで `Ω_B` のように添字を付けて区別し、変換式を書く。

## 2. 直交位相と雑音レベル

- â = (q̂ + i p̂)/√2、[q̂, p̂] = i。真空の分散 Var(q̂) = Var(p̂) = V_vac = 1/2。
- 回転した直交位相: x̂_θ = q̂ cos θ + p̂ sin θ = (â e^{−iθ} + â† e^{iθ})/√2。
- コヒーレント状態 |α⟩: ⟨x̂_θ⟩ = √2 |α| cos(θ − arg α)。
- 雑音レベル: S_dB = 10 log10(V / V_SN)、V_SN = V_vac = 1/2（ショット雑音）。
- 純損失（透過率 η）: V_out = η V_in + (1 − η) V_vac。直列の損失は透過率の積。光路に沿って分布した受動の損失は、同じ合計の一点の損失と等価（利得や付加雑音が同時に働く区間を除く）。
- 位相に依らない付加雑音（N 光子/モード）: V → V + N、すなわち ΔV/V_SN = 2N。
- モードあたりの光子数: N = ∫ n(f) |ũ(f)|² df（n(f): 光子数スペクトル密度 [1/Hz]、ũ: 規格化したモード関数のスペクトル）。実効的なモード時間 τ_eff = (∫u dT)²（u は ∫|u|² dT = 1 に規格化）。

## 3. スクイーズ演算子とスクイーズ角

- S(ξ) = exp[(ξ* â² − ξ â†²)/2]、ξ = r e^{iφ_ξ}、r ≥ 0。
  S† â S = â cosh r − â† e^{iφ_ξ} sinh r。
- 分散: Var(x̂_θ) = (1/2)[e^{−2r} cos²(θ − φ_ξ/2) + e^{2r} sin²(θ − φ_ξ/2)]。
- **スクイーズ角 θ_sq** = φ_ξ/2（分散が最小になる直交位相の角度、mod π）。反スクイーズ角は θ_sq + π/2。

## 4. 光の位相の符号

- 場は正周波数成分で書く: E(t) ∝ A(t) e^{−iω0 t}。複素振幅 A の偏角を光の位相 φ とする（A = |A| e^{iφ}）。
- 瞬時周波数が ω0 + 2πδν(t) のとき: φ(t) = −2π ∫ δν dt。周波数を +Ω_sh ずらしたビーム: A = |A| e^{i(φ − Ω_sh t)}。
- AOM: +1 次回折で A → A e^{i(φ_RF − Ω_RF t)}、−1 次で A → A e^{−i(φ_RF − Ω_RF t)}（φ_RF: RF 駆動の位相）。
- 伝搬: 長さ L の区間を通ると A → A e^{+iψ}、ψ = β(ω0) L = n_eff ω0 L / c > 0。**区間が長くなる（温度上昇・ストレッチャで伸ばす）と ψ は増える。**
- ストレッチャ:
  - 物理的な伸び δL が与えられたとき: δψ = ξ_eo β δL、ξ_eo ≈ 0.78–0.80（光弾性による補正、T16 で確認）。
  - **光路長の変化 δOPL が与えられたとき（915B の仕様 "optical path length measurement" はこちら）: δψ = 2π δOPL/λ0。ξ_eo を重ねてかけない。**
- アクチュエータの符号: 各アクチュエータは利得 k_act [rad/V]（符号付き）を持ち、k_act > 0 は「正の電圧で、そのアクチュエータがある区間の ψ が増える」ことを表す。実機の極性が分からないときは `loop_sign ∈ {+1, −1}` をパラメータにする。
- ポンプ位相 φ_p: ポンプ（2ω0）の複素振幅の偏角。
- 縮退パラメトリック相互作用: H_int = i(κ/2)(β_p â†² − β_p* â²)、β_p = |β_p| e^{iφ_p}、κ > 0。
  このとき ξ = κ t |β_p| e^{i(φ_p + π)}、すなわち
  - 増幅される直交位相: θ_amp = φ_p/2（シードの位相 φ_s が 2φ_s − φ_p = 0 のとき増幅）
  - **スクイーズ角: θ_sq = φ_p/2 + π/2**
- OPA・OPO ごとの位相オフセット: 一般には θ_amp = (φ_p + φ_OPA,0)/2、θ_sq = θ_amp + π/2。上の H_int の形は φ_OPA,0 = 0 に当たる。結合波方程式など別の形を使うノートは φ_OPA,0 の値を明記する（T01・T14）。
- OPA の結晶は**ポンプ経路の区間**としても扱う: 結晶内でポンプが受ける位相 ψ_p,xtal は θ_sq に ½ψ_p,xtal として入る（T01）。
- probe の位相 φ_pr、LO の位相 φ_LO も同じく、それぞれの複素振幅の偏角。
- OPO の記号（T02）: κ_c = キャビティの場の減衰率（半値半幅、HWHM）[rad/s]、Δν_c = κ_c/π = 全幅（FWHM）[Hz]、x = √(P/P_th)（規格化ポンプ振幅）、規格化サイドバンド周波数 Ω/κ_c。Ref B の Ω_B = 2πf/γ_B（γ_B = 2κ_c、FWHM [rad/s]）なので Ω_B = Ω/(2κ_c)。
- パルス励起 OPO の記号（T17）: κ_p = ポンプに対するキャビティの減衰率（HWHM）[rad/s]、Δ_s・Δ_p = signal・ポンプの離調 [rad/s]（キャビティ長の変化では Δ_p = 2Δ_s。符号の定義は `notes/pulsed-opo-source.md` §2 に従う）、ε(t) = 規格化したポンプの包絡線、x_ss = パルスの頂点での規格化ポンプ振幅、T_p = ポンプパルスの長さ [s]。ポンプにも共振するキャビティは、位相 −arctan(Δ_p/κ_p) を持つポンプ経路の区間として扱う。

## 5. 平衡ホモダイン検出（BHD）と DC fringe 信号

- ビームスプリッタ: b̂_1 = (â_s + â_LO)/√2、b̂_2 = (â_s − â_LO)/√2。差電流 i_− ∝ n̂_1 − n̂_2 = â_s† â_LO + â_LO† â_s。
- 実際の 2×2 ファイバカプラは対称形（透過 t、結合 i r）。上の実数形との違いは、差信号の符号 s ∈ {+1, −1}（どちらの出力を検出器の INPUT+ に入れるか）だけなので、s をパラメータとして持つ。
- 強い LO（α_LO = |α_LO| e^{iφ_LO}）のとき: n̂_1 − n̂_2 ≈ √2 |α_LO| x̂_θ、**θ = φ_LO**（signal モードの枠で測る直交位相）。
- コヒーレントな signal/probe（位相 φ_pr）との DC 干渉: ⟨n̂_1 − n̂_2⟩ = 2|α_LO||α_pr| cos(φ_LO − φ_pr)。
  差信号の零点は φ_LO − φ_pr = ±π/2。Ref D の設定点の初期値は +π/2（D02、D06）。
- **Ref D の対応付け:** 915B のない腕 = "LO"、915B のある腕 = "pr"、b̂_1 → PDB450C の INPUT+。実機の極性は不明なので `loop_sign` をパラメータにする（T15）。
- squeezed 光を測るとき、測られる直交位相の角度とスクイーズ角の差 Δ = φ_LO − θ_sq が 0 のとき squeezing、π/2 のとき反 squeezing を測る。
- 回路雑音のクリアランス C = （ショット雑音のパワー）/（回路雑音のパワー）（測定周波数で、線形比）。差し引かない回路雑音は純損失と等価: η_el = C/(1 + C)（T12・T13）。

## 6. 位相ジッタと測定値

- 準静的な残留位相誤差 δ(t)（平均 0）と設定点のずれ Δ0 があるとき（T04）:
  V′ = (V_− + V_+)/2 − (V_+ − V_−)/2 · cos(2Δ0) · χ、χ = ⟨cos 2δ⟩。
  - ガウス分布（分散 σ²）: χ = e^{−2σ²}。Δ0 = 0 なら V′ = (V_− + V_+)/2 + (V_− − V_+)/2 · e^{−2σ²}（厳密）≈ V_− cos²σ + V_+ sin²σ（σ ≪ 1、§7-1 の式。σ = θ_rms）。
  - 正弦波の dither（振幅 m）: χ = J0(2m)。独立な成分の χ は積になる。
- σ² に入れる位相雑音の周波数範囲: 下限は測定時間（または較正の間隔）の逆数。**上限は ESA の RBW や検出器の帯域ではなく、光源のスペクトルが平らな範囲で決まる**（測定周波数 f_s から f だけ離れた位相雑音は、f_s ± f の反 squeezing を f_s に混ぜる。光源のスペクトルが平らなら遅いジッタと同じに効く）。積分範囲はノートごとに明記する。
- OPO の時間モード（ns 級）では、上限はモードの帯域（約 κ_c）で決まる（T17）。

## 7. スペクトル密度と雑音

- PSD はすべて**片側**: ∫_0^∞ S_x(f) df = Var(x)。
- 位相雑音 S_φ [rad²/Hz]、周波数雑音 S_ν [Hz²/Hz]、S_φ(f) = S_ν(f)/f²。片側帯域の位相雑音 ℒ(f) = S_φ(f)/2（線形）。
- 白色の周波数雑音 S_ν = h0（片側）のとき、Lorentz 線幅（FWHM）Δν = π h0。
- 遅延 τ の自己干渉（遅延差のある干渉計）: S_Δφ(f) = 4 sin²(π f τ) S_φ(f)。
- 相対強度雑音 RIN: S_RIN(f) [1/Hz]、片側。
- **光源の位相は出射時刻で評価する**（時刻 t に区間の出口に着く光は、群遅延 τ_g だけ前の t − τ_g に光源を出た）。この遅延による効果を、伝搬位相の周波数依存として二重に数えないこと（T05）。

## 8. Fourier 変換（GNLSE と数値計算）

- 連続: Ã(Ω) = ∫ A(T) e^{+iΩT} dT、A(T) = (1/2π) ∫ Ã(Ω) e^{−iΩT} dΩ（Agrawal の規約）。
  この規約で ∂/∂T → −iΩ。
- 数値（numpy、格子 T_n = n Δt、N 点）: Ã(Ω_k) = N Δt · numpy.fft.ifft(A)[k]、Ω_k = 2π · numpy.fft.fftfreq(N, Δt)[k]。
  逆変換: A = numpy.fft.fft(Ã) / (N Δt)。
- GNLSE の線形演算子（周波数領域）: D̂(Ω) = −α/2 + i[β(ω0 + Ω) − β0 − β1 Ω]（α: パワーの損失係数）。自己急峻化の因子は (1 + Ω/ω0)。
- Raman 応答は時間格子で標本化せず、周波数領域の解析式 h̃_R(Ω) で与える（Δt ≳ 3 fs で標本化すると見かけの遅延になる、T06）。
- 既存の GNLSE コードや scipy を使うときは、その符号と規格化をこの節と照合し、ラッパーで変換すること（AGENTS.md）。

## 9. 光路の区間とロックの表し方（D11・D47）

- 光路は区間の列。各区間は次を持つ:
  - id、長さ L [m]、群屈折率 n_g、群遅延 τ_g、β2・β3
  - **伝搬の向き** d ∈ {+1（光源 → 検出器/GBS）, −1（逆向き）}
  - **偏光: 2×2 の Jones 行列 J**（逆向きに通る光には J^T がかかる。相反性）。PM ファイバでは軸のラベル a ∈ {slow, fast} を使う簡易版も選べる（T09）
- 区間の位相 ψ_seg(t) = 名目値 + 雑音。雑音源は区間ごとに持ち、**係数は「区間 × ビーム」ごとに持つ**（同じ区間でも、軸・周波数・向きの違うビームは係数が違いうる。共通の区間でも相殺は自動ではない。例: OPO の離調、T02・T10）。
- PM ファイバの 2 軸の位相差 Δψ_b = ψ_slow − ψ_fast の温度係数 K_T = ∂(Δψ_b/L)/∂T は**負**（名目 −2.05 rad/(m·K)、PM15-U25D で −1.7〜−2.9、Ritari 2004、T09）。軸ごとの温度係数は dψ_slow/dT = L·C_T、dψ_fast/dT = L(C_T + |K_T|)（C_T ≈ 44 rad/(m·K) は §4 の熱位相係数、T08）。D11 の +2.4 rad/(m·K) は置き換え。
- 温度・ストレッチャなどの要因ごとに、位相と群遅延への効き方を別々に持つ（温度は位相と群遅延の両方、ストレッチャは主に位相、T03）。
- 区間の中の雑音の空間的な構造を選べる: 一様（区間全体が同じ揺れ）、独立（場所ごとに無相関）、混合（T08）。逆向きに伝搬する光は、同じ区間の雑音を異なる時刻でサンプルする（区間内の位置 x を通る時刻が t + n_g x / c か t + n_g (L − x)/c か）。
- ビームの位相 = 光源の位相（出射時刻で評価、§7）+ 通る区間の ψ の和。
- **ロック** = ビームの位相の線形結合（例: φ_LO − φ_pr）を設定点に保つこと。誤差 e(t) = （その線形結合）− 設定点。
  機器が別の符号で誤差を定義する場合（例: DSC1 は e = S − v、マニュアル p.18）は、その機器のブロックの内部で変換し、ブロックの外ではこの規約に揃える。

## 10. 評価の指標（D12・D31・D46）

- (i) 各ポート k で、squeezed 光と LO_k の相対位相: Δ_k = φ_LO,k − θ_sq,k（BHD で測れる値）。
- (ii) GBS 入力での、ポート k とポート 0 の squeezing 角の差: Θ_k = θ_sq,k − θ_sq,0（D31）。結果は次の 4 つに分けて出す。
  1. ロックされる光路の雑音の残差
  2. 共通点（probe の分岐点、参照光の配送点）の揺れ
  3. 時間多重によるレーザー位相雑音の相関の崩れ φ_L(t − τ_j) − φ_L(t − τ_k) のうち、ロックの帯域外の部分（帯域内は同じレーザーの probe なら打ち消される。T05・T10）
  4. squeezed 光だけが通る区間の雑音（光源 → 振り分け素子 → probe の取り出し点、probe の入れ点 → GBS。振り分け素子の位相を含む。T10）
- (ii) と並べて、ポート間の波束の重なり（wave-packet overlap）も出す（T03）。
- 混入光子は「検出ゲートあたりのクリック数（両偏光）」と「squeezed 光のモードの中の光子数」（§2 の N）の両方で出す（D46）。
