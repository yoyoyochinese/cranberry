## 0. 結論（要約）

- **blocker はない。** 式・符号・係数 2・単位・損失の帳簿・QNL の閉じた形の積分は正しい（§3）。
- **major が 4 つ。** (M2C-01) ゼロスパンの V′ を記録した δ から作るので、D68-5 が勧める `antialias: boxcar|fir` を指定すると速い位相ゆらぎ（時系列の dither を含む）が消え、Ref C の 30 MHz の squeezing が 0.46 dB 良く出る。(M2C-02) 3 段の積み重ねは掃引の格子の約 9 % で線形に不安定で、安定性の検査がない（不安定な点は 0.23–0.53 rad を「結果」として出し、監視は外れを報告しない）。(M2C-03) EOM と鏡のレンジの飽和を誰も見ていない（h_ref_conduit の上端・f_12 の下端で EOM が 11–13 % の時間クランプし、残差が非線形に跳ねる）。(M2C-04) 名目のファイバ雑音は、Ref C で唯一の測定値である Fig. 2 右（ロックなしの 1 s）と低周波で桁違いに合わない。
- **D67-4 の判定:** 足りない雑音源のブロックはない。0.056 と 0.1 rad の差は (a) 論文の 0.1 rad が 21 % の損失と縮退した当てはめの値で、さらに dither の**ピーク** 4.5° を rms と比べていること、(b) 本当に残る差（η = 0.79 なら dither 以外に約 0.06 rad）は EOM ループの帯域（論文は「kHz 域」）と、kHz 帯のファイバ雑音の大きさ（T08 の形は Ref C の建物内の配線を表していない）で説明される。推奨は §4。
- **D67-5 の判定:** dither による「周波数に依るデコヒーレンス」は**すでにモデルに入っている**（角度のゆらぎは周波数に依らず、dB での効果が V₊ − V₋ とともに減る: 30 MHz で 0.45 dB → 0.5 GHz で 0.15 dB → 0.69 GHz で 0.09 dB）。別のブロックは要らない。0.69 GHz の 0.67 dB の差は位相雑音では作れず（0.17 rad が要り、30 MHz が −2.5 dB になる）、どの共通の (η, x, σ, 線幅) でも再現できない。測定点に固有のずれ（BHD_B の 0.83 GHz の干渉の近く、暗雑音のクリアランスが最低の 5 dB）として記録する。§5。

## 3. 確認して正しかったもの（§7.4 の点検表）

1. **式とノート（1）:** `quantum_noise_power` の P(Δ) = p_mean − p_delta cos 2Δ、Q(Δ) = q0 + q1 cos 2Δ + q2 cos² 2Δ は T14 §6.1 と一致。プリセットの閉じた形（I1・I2・J11・J22・J12）を直接の数値積分と `qnl_band_integrals` に対して確認: 相対差 ≤ 4×10⁻¹⁶（quad）、≤ 1.4×10⁻¹²（台形）（`m2_refC_qnl_integrals.py`）。BHD_B の dip（r 0.3–0.9）を QNL の帯域に入れても、センサ雑音の rms は ≤ 1.1 %、ΔP は −7…−9 %（ループ利得が少し下がるだけ）で、平らな |H| の近似は十分。
2. **符号（2）:** φ_p := 2θ_sq（`p_bhd`）と φ_OPA = −π で Δ = φ_LO − θ_sq（conv §4・§5）。誤差の傾きは Δ₀ > 0 で正、K_i < 0 で負帰還。鏡・伸長器の段は正の K_i で、上の段の駆動を積分して打ち消す（負帰還）。交差周波数の式 |K₁C₁| = 1/K_d（f_u1）、|K₂C₂| = K₁（f_12）、|K₃C₃| = K₂（f_23）はプリセットの K_i の式と一致。
3. **2 倍の因子（3）:** 復調の 2S（RF と基底帯域で同じ。I = b at φ_d = −π/2）、radiometer の S_P̂ = 2∫S_x²、周期定常の重み 2⟨2 sin²θ S_v⟩（D65-1）、R± の定義（T02、κ = π·FWHM、Ω/κ = f/(FWHM/2)）、RF モードの雑音の標準偏差 √(S f_b/2)。
4. **単位（4）:** m = π·(V_pp/2)/U_π = 0.0785 rad（±4.5°）、rms 相当 m/√2 = 0.0555 rad（χ = J0(2m)）。EOM の利得 π/U_π rad/V。
5. **FFT（5）:** `radiometer_mc` は `fft_agrawal` を使う（conv §8）。
6. **収束（6）:** `test_refC_convergence_fsim_chunk_seeds` が通る（f_sim ×2・×4、seed 10 本）。
7. **トグル（7）:** 雑音をすべて切ると dither 以外の残差は 0.00 mrad。
8. **損失の帳簿（8）:** η = 0.85/(0.99·0.97) · 0.9294 · 0.97（QE、検出器）· 0.99（脱出効率、光源）= 0.79。暗雑音を引く設定では回路雑音の要素は無効（二重にならない）。ファイバの区間の損失は 1 回だけ。
9. **出典の印（9）:** 論文の値（1550 nm、1.75 GHz、15 %・8 %・21 %、U_π 4 V、200 mVpp、1 MHz、8–300 MHz、11 dB、RBW 300 kHz・VBW 300 Hz・0.6 s、180 m・1 km、0.83 GHz の dip）は本文・図と一致。仮の値には [AE]・UNVERIFIED がある。
10. **保護リスト（10）:** 消されたものはない。時系列と解析的な dither の両方、2 乗則のオーバーレイ、ランプ（オフ）、掃引の軸が残っている。

その他:
- **D66-4 の RAM の修正:** 基底帯域・RF の両方で p = (P − p_dark)(1 + a sin) + p_dark。refC は `p_dark` を与えている（5f96bd5）。
- **D67-2 の cw_sideband の読み出し:** ゼロスパンは各ブロックの `f_s_hz`、掃引スペクトルはビンごとに `_at_fs` で V±・θ_off を線形補間（格子の外はエラー）。χ_HF・χ_dither は周波数に依らない（正しい: 角度のゆらぎ）。50 MHz 間隔の線形補間の誤差は R₊ の曲率から ≲ 0.02 dB。
- **`t_settle_s`:** モーメントとゼロスパンが読む系列の両方から最初の 0.02 s を除く（`metrics.py:683`）。記録の長さの検査は除いた後で 0.6 s を満たす。
- **ロック時間:** 0.1804 rad/s·(t − 300(1 − e^{−t/300})) = 32.5 + 0.03 rad → t ≈ 402 s（6.7 min）。VT-21 の 2 つの時間（伸長器のレンジ、全レンジ）は時間領域で 1 %・5 % に入る。
- **時系列 dither の標本化:** f_sim = 4 MHz で 1 周期 4 点、記録の間引き 25 で位相が 1/4 周期ずつ進むので、点標本の ⟨cos 2δ⟩ は cos² m（J0(2m) との差 m⁴/12 = 3×10⁻⁶）。
- **D67-6:** センサ雑音だけの残差 5.5 mrad は VT-20(c) の独立な式と 10 % 以内（再計算はしていないが式と重みを読んで確認）。

## 4. D67-4 の判定（名目の dither 以外 約 7 mrad、論文の合計 約 0.1 rad）

**判定: 雑音源のブロックの欠落ではない。差の半分は論文の側の勘定、残りは「EOM ループの帯域」と「kHz 帯のファイバ雑音の形」という 2 つの軸の名目値の問題。0.1 rad を目標にしてはいけない。**

1. **論文の 0.1 rad は精密な測定値ではない。** Fig. 5 の当てはめのパラメータで、損失 21 % と組になっている。Fig. 4 の数だけでも (η, σ) は縮退していて σ = 0.04–0.09 rad を許す（§2.2）。さらに論文は「±4.5° の変調が 0.1 rad ≈ 5.7° とよく合う」と**ピーク振幅**を rms と比べている。dither の squeezing への効き（χ = J0(2m)）に相当する rms は m/√2 = 3.2°（0.0555 rad）なので、論文の勘定は dither の割合を √2 倍に見ている。
2. **それでも残る差。** η = 0.79 を受け入れると、30 MHz の組（10.0 / −4.7 dB）は σ ≈ 0.082 rad、dither 以外 ≈ 0.06 rad を要する（モデルの約 9 倍）。
3. **何で説明するのが物理的に正しいか（優先順）:**
   - (a) **EOM ループの帯域 f_u1**: 論文の記述は「fiber EOM が kHz 域の揺らぎを補正した」[Ref C §2] だけで、名目の 10 kHz は T14 の仮置き。名目のファイバ雑音のままでも f_u1 = 3 kHz で 13 mrad、1 kHz で 33 mrad（§2.1）。**名目を「kHz 域」の中（例えば 1–3 kHz の幾何中心付近）に置き直すのは本文の読み方として正当**で、合わせ込みではない。センサ雑音は √f_u1 で減るので、この読み方はセンサ雑音に制限されないという論文の記述とも整合する。
   - (b) **kHz 帯のファイバ雑音の形**: ロック中の残差は h·f_c/f_u1² で決まり、T08 の f⁻²（Williams 2008 の長距離の実リンク）と f_c = 1 kHz は、建物の中の電線管（空気中に並べた 2 本、一部だけ断熱材）と実験室の巻きを表すとは限らない。Fig. 2 右は低周波が名目より桁違いに静かで、ms の突発（kHz に届く成分）が目立つ（M2C-04）。つまり実際の雑音は「低周波は小さく、kHz 帯は相対的に大きい」形と読める。`f_lo_hz`・`mech_f_c_hz`・`peaks` を軸にし、Fig. 2 で低周波を拘束したうえで kHz 帯の大きさは軸のまま残す。
   - (c) **上限の拘束**: 論文は EOM・鏡のレンジに制限されていないと書くので、kHz 帯の雑音を大きくする方向は EOM の飽和（M2C-03）で上から抑えられる。h_ref_conduit を 10 倍にする読み方は名目の f_12 では飽和を起こすので不適。
   - (d) **レーザー × 光路差**（ΔL = 2 m、h0 = 10⁴ で 44 mrad）は可能だが、同じレーザーから「同じ種類・長さ」のファイバで、レーザーの線幅も不明。根拠が弱いので軸のまま（名目にしない）。
   - (e) ρ_conduit は kHz 帯（f_ρ より上）には効かないので、残差の差の説明にはならない（Fig. 2 の低周波の説明には効く）。
4. **推奨（調整役・ユーザの判断）:** `refC_nominal` の f_u1 を「kHz 域」の中に置き直す（理由: 本文）。Fig. 2 右の VT を加えてファイバ雑音の低周波を拘束する。VT-20 は 0.1 rad を「帯」として扱う今の形のままでよい（0.1 rad を目標にしない）。

## 5. D67-5 の判定（0.69 GHz: モデル −3.67 dB、論文 −3.0 dB、dither による周波数依存のデコヒーレンス）

**判定: 新しい仕組みは要らない。dither の効果の周波数依存はすでに入っていて、0.69 GHz の差はその仕組みでは説明できない。**

1. **論文の「0.3 GHz より上でも追加のデコヒーレンス、0.5 GHz より上では無視できる」[Ref C §4、文献 22 = Franzen et al. 2006] は、周波数に依らない角度のゆらぎが V₊(f) − V₋(f) を通して効くことそのもの。** 名目（η 0.79、x 0.5585、m/√2）での squeezing の劣化: 30 MHz 0.450 dB、0.25 GHz 0.307、0.3 GHz 0.267、0.5 GHz 0.147、0.69 GHz 0.086、1.21 GHz 0.028 dB（`m2_refC_fig4_fit.py` §4）。モデルの V′(f) = R₋ cos² + R₊ sin² の形に含まれている（cw_sideband の V±(f) に χ_dither をかける、§3）。
2. **f_m と κ の比による別の効果はない。** 1 MHz の位相変調は f_s ± 1 MHz を混ぜるが、光源のスペクトルは 875 MHz（HWHM）の尺度でしか変わらないので、ゆっくりした角度のゆらぎと同じ（conv §6）。相対の補正は (f_m/κ)² ~ 10⁻⁶。McKenzie (2005) の Eq. (6) の J0(θ₁)² も同じ準静的な扱い（T14 §6.2 の注のとおり 3 次で違う）。
3. **0.69 GHz の 0.67 dB の差は位相雑音では作れない:** −3.0 dB にするには σ = 0.173 rad が要り、そのとき 30 MHz は −2.54 dB（論文 −4.7）。0.69 GHz では反 squeezing も論文の方が高い（5.2 vs 5.0 dB）ので、損失や位相に依らない付加雑音（squeezing 側 +0.07、反 squeezing 側 +0.16 が要る）、暗雑音の差し引きの誤差（反 squeezing を下げる方向）でも両方は合わない。(η, x, σ, 線幅) を全部自由にしても 0.69 GHz に −0.38 dB 残る。1.21 GHz は 0.05 dB 以内で合うので、全体の形の誤りでもない。
4. **推奨:** モデルに新しい仕組みを入れない。差は「BHD_B の 0.83 GHz の干渉の近く（クリアランスが 4 点で最低の 5 dB）での測定点に固有のずれ」として DECISIONS に記録する。`test_refC_zero_spans_vs_fig4` の squeezing の許容 0.7 dB は 0.69 GHz のためだけに広いので、周波数ごとの許容（0.69 GHz だけ 0.7 dB、他は 0.5 dB）にして理由を書くとよい。
