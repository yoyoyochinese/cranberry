### 2.1 式の確認（読み）

- 1 ゲート・出力 d の平均: λ_d = r·[qe(μ(1 ± V cos X)/2 + b) + dark]（コードは `qe*b + dark + m*(1 ± vc)`、m = qe μ/2）。μ は 2 出力の合計で検出器の前、qe を掛けて検出光子。規約 §2 の「光子数」と整合。
- クリック検出器: k = 1{u < 1 − e^{−λ}}、PNR: 1 個の一様乱数の逆関数法でポアソン（上限 10⁴）。
- 不感・回復: r = 0（Δt < t_dead）、1 − exp(−(Δt − t_dead)/τ_rec)。Δt は同じ出力の最後のクリックから。ゲートは 1 ステップの中に h/n 間隔で並べる。名目の F_liu20 ではゲート間隔 6.4 µs ≫ 回復なので効かない（C-3 の「データスロットへの回復」は別の問題）。
- 推定量: λ̂_d = −ln(1 − n_d/G)（n_d/G ≤ 1 − 1/(2G) でクランプ）− dark、cos X̂ = (λ̂_1 − λ̂_0)/(V(λ̂_1 + λ̂_0))。2 出力は独立な二項分布 Bin(G, 1 − e^{−λ_d})、パラメータ (m, X) と (λ_1, λ_0) は 1 対 1（λ_1 + λ_0 = 2m + 2·dark、λ_1 − λ_0 = 2mV cos X）なので、不変性から内点では真の最尤推定。境界（|c| > 1、λ̂ < 0）ではクランプで、制約付きの最尤と同じ側に落ちる。

## 3. A-2: 乱数のチャンク不変

カーネルは各ステップで `2·n_max` 個（n_max = ⌈f_gate·cal·h⌉）を必ず読み、j ≥ n のゲートの分も読んで捨てる（G11）。マスクで数えないステップも同じ。`counting_noise` が off なら補充も消費もしない。`DrawBuffer.refill` は前の区切りの消費数を検査する（不一致で `DrawCountError`）。区切り {1, 999, 4000, 15000}、7 × 2857 + 1、20000 の 3 通り（不感あり、窓 330 µs、ゲート 1.65/ステップ）で、n0・n1・x_hat・t_last・acc・window_index がビット単位で一致した（§F）。

## 4. A-3: 遅いループの置き場所・遅延・台帳

1. **置き場所:** プローブは F_k を逆向きに速い軸で通るので、F_k の上のストレッチャ（両軸で係数 1、F_common の `F*.stretcher.all.phase`）はプローブに見え、速いループ（f_u ≈ 1 kHz ≫ f_c = 2 Hz）が打ち消す。TEC は速い軸に k_T + |K_T|、遅い軸に k_T で効くので、打ち消した後に squeezed 光に −|K_T|/(k_T + |K_T|) ≈ −4.5 % だけ残る（実用にならない逆符号の小さな利得）。したがって「速いセンサーが見ない所に入れる」＝設定値の移動か REF_k は物理的に正しい（C-8 は説明の補足）。
2. **遅延:** pcf1 の窓平均（重心 T/2）＋次の窓の間の保持（T/2）で T_int。`dbs1.pid` は保持された値を毎サンプル積分するので出力はランプ。窓の誤差の漸化式は e_{n+2} = (1 − a/2)e_{n+1} − (a/2)e_n + Δd̄（a = 2πf_c T）で、Jury の条件から 0 < a < 2、すなわち **f_c·T < 1/π = 0.318**。時間領域のモデルで 0.30 は収束、0.33 は発散（`p6_wp6c_slowloop.py` 1）。検査の e^{−s(T+τ_L)} の連続近似では 0.25 で、安全側。名目 0.1 では極 |z| = 0.56。
3. **台帳の行:** `dbs_win_band_per_h` = ∫ f²/((f² + f_lo²)(f² + f_c²)) df を部分分数 (b·atan(f/b) − a·atan(f/a))/(b² − a²) で [f_win,lo, 1/T_rec] に評価しており、F_common の `win_band_per_h`（T08 の 1 kHz の角あり）に型 1 の感度を掛けて角を落としたものと一致（帯域が f_c より下なので角を落としても差はない）。f_c = f_lo の特異点の正則化も正しい。1 s の実行で 2 層の成分 2 は 20.4 mrad（30 s の時間ループ 18.4 と整合、遅延を無視した感度で少し楽観的）。

## 6. A-5: シードの漏れと入れる位置

### 6.1 squeezer の前（名目、C-1・C-2）

モデルでは `dseed0/1` は `sqz0/1` と同じ区間の列（PUMP・XTAL を θ-単位で通る）で、X_s − π/2 は Θ_k の厳密な写し（§5 の diag）。これは「シードの出力位相 = squeezing 角」という高利得の極限の仮定で、次の 2 点が抜けている。

- **位相感応の増幅（C-1）:** α → α cosh r + α* sinh r（増幅の軸を実軸に）。準備位相 0 と π/2 はともに固有の直交位相なので差 π/2 は保たれるが、
  | r | 強度比 \|α_k/α_0\|² | 同じ入力での可視度 | ポート k の入力位相の利得 | ポート 0 | ±π/4 の準備での出力の差 |
  |---|---|---|---|---|---|
  | 0.5 | 0.135 | 0.648 | 2.7 | 0.368 | 0.705 rad |
  | 1.0 | 1.83×10⁻² | 0.266 | 7.4 | 0.135 | 0.269 rad |
  | 1.8（名目） | 7.47×10⁻⁴ | 0.055 | 36.6 | 0.027 | 0.055 rad |

### 7.1 B-6: ヘテロダインのロック点と符号

- 規約 §4: 周波数 +f_sh のプローブ A_pr ∝ e^{i(φ_pr − Ωt)}、参照 e^{iφ_ref}。光電流の交差項 2Re(A_pr A_ref*) = 2cos(Ωt − X)、X = φ_pr − φ_ref。`demodulator` の参照 2cos(Ωt + φ) を掛けて低域通過すると I = K cos(X + φ)。ブロックの基底帯の表現 (a, b) = K(cos X, sin X)、I = a cos φ − b sin φ = K cos(X + φ) と一致。零点 X = π/2 − φ（傾き −K、F_common のループの符号と同じ）。
- `sign = −1` で rf = −c、X − π/2 = +c。ストレッチャは F_k のプローブ（逆向き）と squeezed 光に同じ +Δψ を与えるので Θ_k − Θ_0 = c_k − c_0。`mii` の設定値 S[slot_k] − S[slot_0] と同じ向き。
- K に依らないこと: ±1.5 rad の 4 組の表（Δ(p_1 − p_0) は最大 4.1 rad）で、ロック座標の偏り（区間の後半の平均）の最大は名目 3.8 mrad、K/2（可視度 0.5 とパワー 1/4 は同じ K なので同じ値）で 17.5 mrad。後者はポート k の 1 区間だけで、dwell を 20 ms にすると名目 ≤ 2.1 mrad、K/2 ≤ 4.2 mrad に下がる。K を半分にするとループ利得が半分になりポート k の残差が増える分で、ロック点の K 依存ではない。Θ の偏りは 4–26 mrad だが、これは指定と無関係な Θ の雑音（squeezed だけの区間など）。**D95-4 の「1.5 mrad 以内」（ロック座標、小さい段差）は成り立つ。**
- 注記: 復調の DC オフセット v_off があると零点は arcsin(v_off/K) ずれ K に依存するが、これは全設定に共通の定数でプログラムの零点に吸収される（K が動くとプログラムと無関係にロック点が動く、既存の性質）。

### 7.2 B-7: 悪い構成の式

- DC の設定値: K cos X = K_cal sin(−p)（sign −1、v_fringe = K_cal）から X − π/2 = arcsin((K_cal/K) sin p)。テストの表 [[0.3, −0.2], [−0.2, 0.3]]、K_cal/K = 2 で arcsin(2 sin 0.3) − 0.3 = +0.332、arcsin(2 sin(−0.2)) + 0.2 = −0.209 rad。D95-4 の「+0.33／−0.21」と一致し、テストは 0.02 rad で通る。(K_cal/K)|sin p| > 1 ではロック点がなく、傾きは cos p で落ちる（ヘッダのとおり）。
- dither: 復調の位相 p は I ∝ sin X·cos p の振幅だけを変え、極値 X = 0 のロック点は動かない。誤差は −p、Θ では −Δ(p_k − p_0)（テストで確認）。|p| = π/2 で傾き 0（ループが開く）も式どおり。

### 7.3 B-8: `step_response` と `setpoint_slot`

- 折り返し: ロック座標は周期 2π で目標の周りに折り返す。表の値は [−π/2, π/2] なので |Δ| < π で問題ない（π/2 の歩みは Δ = π/2 だけ）。Θ は周期 π で同じことをするが、Δ(p_k − p_0) は最大 2π（一様の表）になり、|Δ| ≥ π/2 では区間の初めの値が目標の反対側に折り返されて立ち上がりと行き過ぎが誤る（P-2）。正確な 1 次応答（τ = 0.16 ms）で:

  | Δ | 立ち上がり（正しくは 0.352 ms） | 行き過ぎ（正しくは 0） | 整定 |
  |---|---|---|---|
  | 0.40 | 0.350 ms | 0.000 | 0.600 ms |
  | 1.20 | 0.350 ms | 0.000 | 0.770 ms |
  | 1.60 | 0.000 ms | 0.963 | 0.820 ms |
  | 2.40 | 0.000 ms | 0.622 | 0.880 ms |
  | 3.09 | 0.000 ms | 0.481 | 0.920 ms |

  整定（|e| を折り返して判定）と偏りは正しい。直し方: 区間の中で Θ を時間方向に周期 π で unwrap し g_prev から始める、または |Δ| ≥ π/2 を NaN にする。
- Θ の零点: [t_first/2, t_first) の円平均（周期 π）を引く。F_* では t_first = t_settle = 5 ms で、ロックの引き込みは 1 ms 程度なので後半には過渡は残らない。マスクを無視するのは P-6。
- 他ポートとの比較: 同じ非零の段差のポートの組だけ整定・立ち上がりの差、全組で (y_k − y_l) − (g_k − g_l) の偏り。式どおり。
- ポート k の整定（P-4）: dwell 20 ms で 16.6–19.9 ms または NaN。10 mrad の許容がポート k のロックの雑音と同程度のため。
- `setpoint_slot` と `mask_slot`: カーネルは毎サンプル x = θ_k − θ_0 − Θ_set − S[slot_k] + S[slot_0] を折り返して書き、マスクは積算（モーメント・雑音レベル・分解）にだけ効く。設定値の引き算は記録された `metric.mii.port1` にも入るので、`step_response` が足し戻す S[slot_k] − S[slot_0] と整合する（足し戻した後は折り返していないが、`table_of` で目標の周りに折り返し直す）。

### 7.4 B-9: squeezer のフックへの挿入

F_common の時間ループは上から順の seq で、`squeezer` の seq（OPO の長さ・ポンプのロックの置き場所）は `path.phase` より前、`liu0` より前。`prog` はそこに追加されるので、`rf.prog.port<k>`（`dem0/1` が読む）、`ctrl.prog.target<k>`（`sup0/1` の `slip_center_slot`、`mii` の `setpoint_slot` が読む）は同じステップの中で書いてから読まれる（読みの前に書く、遅延 0）。`prog` は `t` だけを読み帰還路の外にあるので、ループ遅延（`lock_extra_delay_s`・`chk.lock_stability`）は変わらない。並列の兄弟の分岐の規則（D55-2）にも触れない（フックは並列の中にない）。参照ループとコンパイル済みのループの一致はテスト `test_reference_equals_compiled` で 1e-12。

`setpoint_slot` は指令値 c_k をステップで追い、物理のロック点は f_u で追うので、毎回の切り替えの過渡（Δ²τ/2 程度の面積）がすべて指標 (ii) に数えられる。F_wg6 ＋ `probe/detect_heterodyne` ＋ `program/p6_steps`（π/4 の歩み、dwell 1 ms、30 回、雑音すべて on）で:

| プログラム off（同じ構成で `prog.enabled` false） | 81.9 mrad |
