### 3.1 独立な導出

1 モードのガウス状態（共分散 σ、平均 d、真空 I/2）の真空確率は p0 = π Q(0) = exp(−½ dᵀ(σ + I/2)⁻¹ d)/√det(σ + I/2)。
熱的状態（σ = (n + ½)I）で 1/(1 + n)、コヒーレント状態で e^{−|α|²} を再現する。損失 η の squeezed 真空は a = ½(ηe^{−2r} + 1 − η)、b = ½(ηe^{2r} + 1 − η)。
クリック検出器（効率は η に含めた）では P(クリックなし) = p0 なので、等価なポアソンの平均 −ln p0 は

  −ln p0 = ½ dᵀ(σ + I/2)⁻¹ d ＋ ½ ln[(a + ½)(b + ½)]

で、**シードの項と背景の項の足し算は厳密**（コードの「λ に b′ を足して引く」構造は正しい）。違いは 2 点ある。

閉じた形: λ_± − b′ = m[(A + B)/2 ∓ (A − B)/2 · sin 2β]、A = 1/(a + ½) = 1.442、B = 1/(b + ½) = 0.082、cos X̂ = −(A − B)/(A + B) · sin 2β = −0.893 sin 2β。
β = 0 では dX̂/dβ = +1.79、dX̂/dX = 1.89（縞の傾きが増える）、ゲートあたりの Fisher 情報（V = 1、2 出力）は厳密な式で 1.33（β = 0）・0.90（π/8）・0.18（π/4）、
ブロックの法則ではコードの b′ で 0.198、厳密な b′ で 0.391。overlap 0.5（損失として）でも (A − B)/(A + B) = 0.77、F_bor6 の r = 0.53 でも 0.34。

意味: クリック検出器は変位を「squeezed の直交位相の方向に強く、反 squeezed の方向に弱く」見る。縞の側では 2 出力の変位が直交するので、
β ≠ 0, π/2 では片方の出力だけが強く数えられ、それが縞の位相のずれに見える。b′ の揺れのように 2 出力に共通ではないので打ち消さない。
**「b′ を既知として引く」のは b′ の平均については公平だが、ポンプの入ったスロットでの扱いとしては不十分**（ポンプの位相は β を通して縞に入る:
θ_sq を δφ_p/2 回すと β が −δφ_p/2 動き、X̂ は 0.89 δφ_p だけ動く）。ポンプを切る（`gated`）とA = B = 1 で効果は消える。

窓平均（重心 T/2）→ 次の窓で保持 → 積分器のランプ → 遅延 τ_L の植物、の窓の誤差の漸化式を、τ_L の分だけランプが前の窓にはみ出すことを入れて導いた（φ = τ_L/T ≤ 1）:
