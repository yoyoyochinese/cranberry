## 2. D62-5 の判定: Liu 型ロックの帯域内のレーザー位相の伝達

### 2.1 経路モデルからの導出（conv §7・§9、T10 §2.3 の記号）

ポート j（j = 0, k）。T_a: レーザー → 共通区間の入口（squeezed 光の経路）、τ_j: 共通区間、T_b = T_pd + T_px: レーザー → probe 検出器（共通区間を除く。T_pd は probe の分配 → 入れる点、T_px は取り出し → 検出器）、T_ref: 参照光、τ_xa: アクチュエータの位置（上流端から）の片道の遅延。放出時刻で評価すると

- squeezed 光（GBS、時刻 t）: φ_L(t − T_a − τ_j) + a_j(t − τ_j + τ_xa)
- probe（検出器）: φ_L(t − T_pd − τ_j − T_px) + a_j(t − T_px − τ_xa)
- 参照光: φ_L(t − T_ref)

理想的なロック（probe − 参照光 = 一定）から a_j を解いて代入すると

  θ_j/φ_L = e^{−iω(T_a + τ_j)} − e^{−iω(T_b − T_px + 2τ_j − 2τ_xa)} + e^{−iω(T_ref − T_px + τ_j − 2τ_xa)}

Θ_k = θ_k − θ_0。τ_xa = T_px = 0 のとき因数分解でき、

  H = (e^{−iωτ_k} − e^{−iωτ_0})·[e^{−iωT_a} + e^{−iωT_ref} − e^{−iωT_b}(e^{−iωτ_k} + e^{−iωτ_0})]

で、**B8 の H と一致する**。T10 の式 (12) は、補正 a_k が squeezed 光に届くまでの τ_k の遅れと参照光の項を落としている（probe の項だけを φ_L(t − T_b − τ_k) で引いている）ので、§2.3 の自分のモデルから出ない。

数値: 上の一般式を、F6 の経路（`beam_assembler` の放出時刻、取り出し区間 T_px、アクチュエータを上流端・下流端）にインパルスを通して理想的なロックを再生した結果と比べ、3 組の遅延 × 2 つの位置で 1e-14 で一致（`m4_liu_laser_transfer.py` A）。T_px > 0 か下流のアクチュエータでは B8 の H（T_b = T_pd + T_px）とは 1e-3 以上違う。**F6 は一般の場合も正しく、D62-5 の式は x_a = 0、T_px = 0 の場合に限る**と書き添える必要がある（下流のアクチュエータでは T_b → T_b − 2τ_k、T_ref → T_ref − 2τ_k でポートに依存し、因数分解できない）。

### 2.2 低周波と 0 にできる遅延

- 1 次: θ_j の係数は T_a − T_b + T_ref で、τ_j にも x_a にも依らない → Θ_k では**どんな遅延でも消える**（|H|² ∝ f⁴、D62-5 の記述は正しい）。
- 2 次（x_a = 0、T_px = 0）: |H| ≈ ω²·|τ_k − τ_0|·|Y_k|、Y_k = T_a + T_ref − 2T_b − τ_k − τ_0（ランダムな 5 組で 1e-3 で確認、B）。
- T10 の「T_a = T_b なら 0」: T_a = T_b = 20 ns・T_ref = 20 ns で、10 kHz の |H| は k = 1 で 4×10⁻⁷、k = 31 で 3.8×10⁻⁴（T10 は 0）。
- **ポートに依らない遅延では、0 にできるのは 1 つのポートだけ**: H ≡ 0 ⇔ {T_a, T_ref} = {T_b + τ_k, T_b + τ_0}。例: T_a = T_b + τ_15、T_ref = T_b + τ_0 で k = 15 は 7×10⁻¹⁵、k = 1・16・31 は O(1)（B）。D62-5 の判定は正しい。
- 32 ポートすべてを 0 にするには、指数の多重集合の一致から T_b,k = T_a − τ_k（全 k）かつ T_dn,k + τ_k + T_ref,k = 一定、が要る。つまり **ポートごとの probe 分配と参照光の遅延線**（ポート 0 のものが最長 ≈ τ_31）と、**T_a ≥ τ_31**（ポンプ側の古典的な経路に L_31 以上の遅延）。これらの遅延線は共通点の区間（成分 2）で、ロックされない。L_31 程度のファイバの環境雑音を足し戻すので、実用にならない。
- ポートに依らない遅延の最良: Y = T_a + T_ref − 2T_b − 2τ_0 = 2(√2 − 1)(τ_31 − τ_0) で、最悪のポートの係数が (3 − 2√2)(τ_31 − τ_0)² = 0.17 倍（Y = 0 に比べ）。

### 2.3 実際に効くのは有限のループ利得の項

同じループ利得 L(f) のとき、厳密に（C で 1e-12 で確認）

  Θ_k = H_ideal·φ_L + (A_s/A_p)·(P_k/(1 + L) − P_0/(1 + L))·φ_L、  P_j = probe − 参照光の自由な伝達、A_s/A_p = e^{−iω(τ_j − 2τ_xa − T_px)}

で、第 2 項は低周波で ≈ −iω(τ_k − τ_0)/(1 + L)、すなわち**帯域外の式 (14) に感度関数 |1/(1 + L)|² をかけたもの**。積分器のループ（単位利得 f_u）では、振幅比（第 2 項 / H_ideal）≈ 1/(2π f_u |Y|):

| f_u | 比（|Y| = 2(τ_k − τ_0) = 620 ns、ポート 31・100 MHz） |
|---|---|
| 1 kHz | 257（電力で 6.6×10⁴） |
| 10 kHz | 26（電力で 660） |
| 100 kHz | 2.6 |

したがって現実的な帯域（f_u ≲ 10 kHz、100 kHz でも電力比 7）では、帯域内のレーザー項は感度関数で決まり、**T_a・T_b・T_ref の合わせはほとんど意味がない**。

### 2.4 判定と D31-3・D47-3・線幅の要求への帰結

- **判定: B8（D62-5）が正しく、T10 の式 (12)(13) と D51-5 の式は誤り。** ただし B8 の H は x_a = 0・T_px = 0 の式。
- 帯域内のレーザー項は「同じレーザーの probe なら打ち消される」（D47-3）のとおりだが、残りは遅延差ではなく、ループの抑圧で決まる: S_Θ,L(f) ≈ |1/(1 + L)|²·4 sin²(πf(τ_k − τ_0))·S_φ + |H_ideal|²·S_φ（後者は f_u ≲ 10 kHz で無視でき、100 kHz でも電力で 1/7）。D51-5 の「遅延の合わせ T_a − T_b をパラメータに」は効果がないので外してよい（F6 が経路の遅延をそのまま持つので、モデルとしては何もしなくても正しい）。
- 白色の周波数雑音（S_φ = h0/f²、Δν = πh0）では、(14) の分散 σ² = 2π(τ_k − τ_0)Δν のうち帯域内は約 2(τ_k − τ_0)B（63 m・10 kHz で 0.6 %、630 m で 6 %）。**線幅の要求は D31-3 の元の形とほぼ同じ**: σ_Θ ≤ 10 mrad には Δν ≤ 51 Hz（L_31 = 63 m）、≤ 5.1 Hz（630 m）（D）。ロックが効くのは 1/f・ランダムウォークの周波数雑音とドリフト（ロックなしでは低周波で積分が発散する部分）。

## 3. D62-4・D62-6 と PMD の選択の判定

### 3.1 D62-4（縁の条件 (1 + n_guard)·T_rep）: **正しい**

N_b 個の連続パルスを 1 ポートに送り、n_guard 個を捨てる配置では、スイッチの縁が入るべき隙間は「ブロックの最後のパルスと次のブロックの最初のパルスの間」で、長さ (1 + n_guard)·T_rep（`m4_demux_checks.py` 2: N_b = 4・n_guard = 2 で 3 T_rep、N_b = 50・n_guard = 3 で 4 T_rep）。T11 §3.4 の N_b·T_rep は状態を保つ時間（トグルのレートを決める）で、縁の窓ではない。コードの `check()`（縁 = t_r + 6σ_j + τ_mode + t_ring、トグル f_rep/(2(N_b + n_guard))）と `rise_time_clipping` の位置 0.5(1 + n_guard)T_rep はこれと整合。τ_mode を τ_p の代わりに使うのは ns のモードで正しい。T11 §3.4 の式は未修正（M4-08）。

### 3.2 D62-6（T09 テスト 7、サテライトの符号）: **正しい**

- Gaussian の振幅の重なり O(τ) = exp(−τ²/(8σ_t²)): τ = 1.36 ps、τ_p = 1 ps で 0.2775。10⁻⁴ には τ_p ≤ 0.373 ps（`m4_pol_checks.py` 1）。T09 テスト 7 の「τ_12 = 1.36 ps > τ_p なので 10⁻⁴ 倍以下」は誤り（τ ≫ τ_p の条件を τ > τ_p で使っている）。
- fast 軸の群屈折率は小さい（B_g > 0）ので、fast 軸を通ったクロストーク成分は**早く**着く。conv §8 で遅延 τ は Ã·e^{+iΩτ} なので、U の fast 軸の e^{−iτΩ} は −1.36 ps（`pulse_projection` で −1.360 ps、VT-38 も同じ）。T09 §1.5「遅れる」、§4.3 の表「86 ps 遅れて」は逆（M4-08）。

### 3.3 PMD の `timing_reference`（D62-2）: `centered` を名目に

等分した PSP（±τ/2）と、搬送波での出力偏光への射影で f = ½[u(T − τ/2) + u(T + τ/2)]。時間をずらした参照 u(T − s) との重なりを `pulse_projection` で走査すると、最適は s = 0 で `centered` の式 exp(−τ²/(16σ_t²)) に一致し、s = τ/2 で `psp` の式 [(1 + e^{−τ²/(8σ_t²)})/2]² に一致（3 組で 1e-6、`m4_pol_checks.py` 2）。
psp は「PSP の 1 つに参照を合わせる」= 重心から τ/2 の余分な時間ずれで、δτ_k を重心で合わせる系（D51-6）には当たらない。小さい τ では 1 − η が約 2 倍（100 fs・25 fs で 4.2 % 対 2.1 %）。T09 の式（psp）は保守的な上限として残し、プリセットの名目は centered にする（M4-05）。どちらも等分の最悪の場合で、PSP への分け方の平均ではさらに小さい。

## 4. 確認して正しかったもの

### 4.1 偏光（WP-B7）

- **Faraday と Jᵀ**: 実験室の固定基底で Faraday 回転は向きに依らず R(ρ)、相反な回転なら逆向きは R(ρ)ᵀ = R(−ρ)。`beam_assembler` の順方向 N·U、逆方向 Uᵀ·N（N は区間の出口、逆向きの光が先に通る）は正しい（`beams.py:320-331, 363`、Python 参照と compiled で同じ）。検査: Faraday ミラーの往復 R(ρ)R(ρ) = R(2ρ)、光学活性は打ち消す（`m4_pol_checks.py` 4）。VT-38 の円偏光の最悪の場合 −2ρ = −3.78×10⁻³ rad も式どおり。
- `segment_jones`: su2(a, b, c) = exp(−i(a, b, c)·σ/2)（σ = (diag(1, −1), σ_x, σ_y)、Gordon–Kogelnik）の要素を展開して確認。PM の U = R(θ_out)diag(1, e^{−iΔψ_b})R(θ_in)（slow 基準、Δψ_b = Δψ_b0 + K_T L T_eff、K_T < 0 で fast の温度係数が C_T + |K_T|、conv §9）。T_eff の重みは `Segment.weights` と同じで `segment_phase` と整合（`point` は駆動値を区間の合計とみなす規約で、位相と同じ）。
- SMF の拡散: 1 ステップの dΩ_k ~ N(0, D h)。回転拡散で ⟨cos Θ⟩ = e^{−D t}（小角で ⟨Θ²⟩ = 2Dt）を 400 区間の集団で確認（0.689 対 0.670、統計誤差内）。OU: 厳密な更新、定常分散 σ_Ω² = D/(4πf_c) を確認（0.0301 対 0.0318）、f_c より上で拡散と同じ PSD（片側 4σ²τ/(1 + (2πfτ)²) → D/(2π²f²)）。毎ステップの SU(2) への再規格化。`haar_su2` は S³ の一様点で Haar。
- `pdl_element`: Poincaré 球の平均で |Me|² = 1、範囲 2/(1 + q)…2q/(1 + q)、対称なので Mᵀ = M（PDL は相反）、IL は登録表に 1 回。
- `polarizer_projection`: out_dp = cos²(Θ/2) + 10^(−ER/10) sin²(Θ/2) − 1。
- `coil_birefringence` の `aligned`: 境界の振幅 ε(1 − e^{−iβπR})(1 + e^{−iβ(πR + s)})Σe^{−iβmL_turn}、位相の平均 4nε²、α の平均で random の 2nδ0² に戻る。`per_budget`: x = sin²θ、PER = −10 log tan²θ、`per_lin`・`bend_loss_lin`（D61-5、M1D-03 の修正済み）。
- `pmd_mode_overlap`・`pulse_projection` の Fourier の符号（conv §8）、損失の種類 `fiber`（時間の重なりの要素と二重にならない）。
- T09 テスト 2 の相反性（同じ偏光で arg t_s = arg t_p、直交で 2 arg a）は Jᵀ の恒等式としてコードで成り立つ（VT-38）。

### 4.2 振り分け（WP-B8）

- **クロストークは純損失（ゲートした検出）**: 遅延が時間不変なら、スロット j の漏れはポート k′ で (j − j_target(k′))T_rep ≠ 0 だけずれて着く。各スロットを段ごとに伝搬させ、放出・到着時刻を明示した独立の計算（8 ポートの木、N_b・n_guard を変えて）で、(a) 電力の行列が `transfer_matrix` と 1e-12 で一致、(b) ターゲットのビンには自分のスロットの光（η_sw,k）しかない、(c) ターゲットでないビンの漏れの合計が Σ leak_in·N_b と一致（`m4_demux_checks.py` 1）。ブロック単位（N_b > 1）でも、別のブロックの位置 i ≠ i′ が重なることはない。例外（τ_mode が T_rep に近い ns のモード）は縁の検査（τ_mode を含む）が警告する。
- 木の `transfer_matrix`（同じ深さが同じ駆動、h = popcount(k ⊕ k′)）、鎖（目標の段で t(1 − ε)、通過の段で tε が出る）、`edge_leak`（erf の縁、10–90 % = 2 erfinv(0.8)σ_e）。
- 遅延の設計 L_k = L_0 + k(N_b + n_guard)c T_rep/n_g、σ(k) = K − 1 − k で全ポートが同時に着く（VT-40 7）、トグル f_rep/(2(N_b + n_guard))。
- **δτ_k と δL_k**（D51-6）: `dtau_s`（時間）と `dL_m`（β2·δL_k の GDD、重なりの表へ）は別、`static_mismatch` で両方切れる。温度の項 κ_T L_k⟨ΔT⟩ はリングの現在の行を読む。
- `demux_switch` の ψ_sw = Σκ(πδV/V_π + δΓ_b)、θ_sq → θ_sq + ψ_sw（VT-40 4）、透過 Πcos²(δΓ/2)（駆動雑音は 2 次）、`timeseries` と `declared` で駆動雑音を二重に数えない（`bands()` は declared のときだけ σ_fast² を宣言）。
- **Liu の補助（`liu.py`）**: アクチュエータが x_a にあると probe には n_g x_a/c 遅れて効く（ループ遅延に加わる）、上流端なら 0。F6 の小区間の配置で再現（VT-39）。検出を振り分けの後にすると、スイッチの遅い位相はロックされる区間に入る（VT-39 で 1e-12）。

### 4.3 迷光のゲート（`probe_pulser`、D59-7・D72）

- duty = 1（a ≡ 1）で B10 の CW `stray_photons` を両方の列で再現（ps の Gaussian と ns の指数モード、Rayleigh・Raman・反射。Brillouin の ns の例外は M4-06）（`m4_stray_gating_modes.py` 1）。
- **ポート 15 と 16**（100 MHz、T_f = 320 ns、τ_pr = 10 ns、T_gate = 1 ns）: ポート 15 にはゲートの光子とモードの光子がともに 0 になる時間のずらしがある。ポート 16 にはなく、ずらしの平均はゲートの列もモードの列も CW と同じ（1.0000、0.9999）（2）。L_0 > 0 ならしきい値は下がる（式は一般、説明の「k ≤ 15」は L_0 = 0 の値）。
- モードの重み（conv §2 の N = ∫n|ũ|²df の時間領域の形、狭い線は |∫u a(t − τ)e^{i2πf0t}dt|² を散乱体の遅延で平均）: ランダムな散乱体の位置のモンテカルロと `mode_factors` が統計誤差内で一致（ns の指数モード、f0 = 0 と 12 MHz）（3）。`_trapezoid_in_gate` と `mode_factors` の節点の積分は区分線形で厳密。

## 5. 修正案の詳細

### M4-01（major）: 共有されるスイッチの段

- 物理: 段 s の位相は ψ_s = ψ_s^(0) + κ(πδV_s/V_π + δΓ_b,s)。MZM でも PC + PBS でも κ の項は 2 つの出力で同じ（単一駆動の MZM で E_bar, E_cross ∝ e^{i(φ1+φ2)/2}）。ポート 0 と k が共有する段の遅いドリフトは Θ_k で消える（通過の時刻の差は k·T_rep で、ドリフトに比べて短い）。木では、最上位の異なるビットが m 番目のとき、深さ 1…m を共有する。
- モデル: `demux_switch` は「ポート k の S 段」を 1 つのブロックの中で独立に持つ。ポート 0 とポート k に 1 個ずつ置くと、乱数の流れが別なので相関 0（増分の相関 −0.009、`m4_demux_checks.py` 4）。
- 案: 物理的なスイッチごとに 1 つの状態（バイアス、`declared` でない駆動雑音の標本）を持つ `demux_switch` に変え（木なら 2^S − 1 個、深さで駆動を共有するなら駆動雑音は深さごと）、各ポートの区間の駆動に「アドレスの経路上の段の和」を書く。少なくとも 2 ポートの組（PLAN M4 の「基準ポート 0 ＋ ポート k」）では、共有する段を 1 つのブロックで書き分けること。検査: ポート 1 の Θ_1 のバイアスの成分が 0、ポート 16 が 8κ²σ²t。

### M4-02（minor）: 繰り返しのドリフトの符号

`rep_k = −k(N_b + n_guard)/f_rep`（または説明を「+ = 早く着く」にして他の 2 項の符号をそろえる）。VT-40 7 の期待値を −310 fs に。
