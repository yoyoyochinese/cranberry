## 0. 結論

1. **根本原因（6 点中 5 点）: `loop_stability_check` の制御器が連続の K_p + K_i/s + K_d s で、DSC1 の実際の離散則（p.19、時間ループの `pid` の `dsc1`）ではなかった。** 判定の側の要素の欠落で、時間ループは正しい。
   - DSC1 の積分は e[n] を含む和 h·ΣK_i e = K_i·h/(1 − z⁻¹) = **K_i·h/2** + (h/2)coth(sh/2)·K_i、微分は後退差分 (K_d/h)(1 − z⁻¹) = K_d·s·e^{−sh/2}·sinc。
     つまり離散則は「比例 K_p + K_i·h/2」と「微分の経路の半周期の遅れ」を持つ。D53 の値（K_p = 2.41×10⁻⁴、K_i·h/2 = 7.03×10⁻⁴、h = 2 µs）では **余分な比例項が K_p の 2.9 倍**。
   - D53 のゲインの連続の PID は複素零点 √(K_i/K_d)/2π = **28.3 kHz**、ζ = K_p/(2√(K_i K_d)) = **0.031** の深いノッチを持つ。DSC1 にはこのノッチがない（その周波数での実効の比例 = K_p + K_i·h = 3.9 K_p、ζ_eff ≈ 0.12）。
     連続の判定は 25–31 kHz で |L| を最大 ×6 小さく見積もり、ノッチより下（I が支配）では位相の進みを、上（D が支配）では遅れを取り違える（14 kHz で +9°、52–57 kHz で −30°）。
   - lhs_002（30.8 kHz、Q 66.5）: 共振がノッチの上に乗り、連続の判定は |L(f_res)| = 0.63 だが実際は 1.65 → 不安定。
     lhs_042（14.6 kHz、Q 96.7）: 実際の位相の進み +9° で −180° の交差が共振の山の上（|L| ≈ 1.5）に移る → 不安定。**遅延を足すと交差は逆に山から離れるので、「遅延を 2 µs 足しても安定」は当然**（必要なのは進みで、遅延では作れない）。
     lhs_024・034・044（52–57 kHz、Q 70–98）: D の経路の実際の遅れ（≈ 30°）で −180° の交差が共振より下（49–50 kHz、|L| 0.21–0.26）に移る → 安定。「0.5 µs 遅延を足すと安定と判定」もこれと整合。
   - 修正後の判定は、雑音・量子化を切った時間ループの閉ループ極（成長率と周波数）を定量的に再現する（§2.3）。
2. **残りの 1 点 lhs_057 は判定の誤りではない。** 判定どおり線形に不安定（max |L| = 1.016 → 修正後 1.029）で、時間ループは雑音を切っても 5.9 kHz・std 0.29 rad の**有界なリミットサイクル**になる（縞の sin による記述関数の利得低下 2J₁(A)/A で振幅が止まる）。
   予測の「ロックした」の基準（真の位相の std < 0.3 rad）がこれをロックと数えた。同じものが lhs_118（修正後に不安定、std 0.28 rad）と OAT の f_res = 11.45 kHz・Q 10（修正後に不安定、std 0.24 rad、§4 の「242 mrad」）にもある。線形判定の限界として docstring に解釈を書いた（§3）。
3. **`n_slip`**: 監視器は設定点 +π/2 を中心に round(δ/2π) の変化を数えていた。−π/2 に保たれたループ（δ ≈ ±π）では雑音が境界 ±π をまたぐたびに数える。
   **`lock_supervisor` に `slip_center_rad`（保たれる安定点の δ、mod 2π）を追加**し、境界を不安定点 δ_c ± π に置いた。refD は `loop_sign × coupler_sign` から式で決める（+1 → 0、−1 → π。凍結予測のロックした 326 run すべてがこの規則に従う）。最初の標本で k を初期化する（出発点の縞をスリップと数えない）。

## 2. 原因の切り分け

### 2.1 候補の検討

| 候補 | 判定 | 根拠 |
|---|---|---|

| 大振幅の非線形（縞、飽和） | 原因でない（振幅を止めるだけ） | 0.05–0.4 rad で一定の成長率、飽和なし。lhs_057 などの有界な振動にだけ効く（§3） |
| ZOH・保持・2 点平均 | 原因でない | τ_L（入力 → 出力の遅延の当てはめ）に含まれ、時間ループは明示的な分を差し引く（D61-2）。判定も同じ τ_L |
| 入出力の極、914 の極 | 原因でない | 判定と時間ループで同じ（z 領域の比較で一致） |

| 時間ループのバグ | なし | `pid` の `dsc1` は p.19 の式どおり（M1 レビューで確認済み）。判定の側が別の法則を使っていた |

## 3. 線形判定の限界（docstring に記載した解釈）

- 判定は線形・小信号。縞のロックでは誤差が sin δ なので、振幅 A の振動に対する実効利得は 2J₁(A)/A < 1。max |L| が 1 をわずかに超える点（≲ 1.05）は発散せず、−180° の周波数で数十 mrad–数百 mrad の**有界なリミットサイクル**になる
  （lhs_057・lhs_118・11.45 kHz Q 10: std 0.25–0.29 rad）。max |L| が大きいと縞をまたぐ振動（≈ 1.3 rad rms）か滑り。**max |L| が 1 の ±10 % 程度は境界として扱う**（折り返し・補間・k0 の近似 γ_coh|μ| ≈ 1 の差もこの幅に入る）。
- 「安定」は大振幅の挙動（縞の頂上からの引き込み、飽和、D65-3 の DAC のリミットサイクル）を保証しない。
- 標本化（折り返し）は無視している（refD では z 領域と 2°・7 % で一致、判定は不安定側に寄る）。積分器の Tustin のゆがみ (ωh)²/12 も無視（60 kHz まで |C| の 3 % 未満）。
- 他の離散則（Tustin・前進 Euler、refB・refC・F_common の FPGA/Moku）は従来どおり連続で判定する（MHz 級の更新では差は小さい。必要なら同じ形で足す）。

## 4. `n_slip`（課題 2）

- 原因: `supervisor.py` が k = floor(δ/2π + 1/2) で数え、境界が δ = ±π（+π/2 を中心にしたときの不安定点）に固定されていた。−π/2 に保たれたループでは δ ≈ ±π が境界そのもの。
- 修正: runtime の `slip_center_rad`（`true_in` があるときだけ必須、D34）。k = floor((δ − δ_c)/2π + 1/2)、最初の標本で初期化。refD: `!expr "0.0 if loop_sign * coupler_sign > 0 else pi"`（conv §5・§9。凍結予測のロックした 326 run のすべてで「積 +1 → 枝 0、積 −1 → 枝 ±1」）。F_common の L0・L1 は設定点が安定点（`coupler_sign` +1、dv/du < 0 で K_i > 0）なので 0.0（従来と同じ）。
- 回帰テスト: `tests/unit/blocks/ctrl/test_supervisor.py::test_slips_counted_about_the_held_lock_point`（δ = π に保たれたループに π をまたぐ外乱: 中心 π で 0、旧の中心 0 で > 20）と
  `tests/integration/test_refD_stability_precheck.py::test_refD_slips_counted_about_the_held_lock_point`（refD_nominal で coupler_sign = −1、雑音あり 50 ms: 旧の数え方で > 10 回、新しい `n_slip` = 0）。

## 6. 凍結予測への影響（見積もり、予測は作り直していない）

- **時間ループの数値（PSD、rms、ptp、ロック点のずれなど）は変わらない。** 判定はオフラインで時間ループに入らず、`n_slip` は予測で使われていない。変わるのは分類とそれに依る帯だけ。
- §0・§6.1: LHS の安定は 76 点のまま（lhs_002・042・118 が抜け、024・034・044 が入る）。OAT の安定 70 → 69（11.45 kHz・Q 10 が不安定に）。名目の利得余裕 14.0 → 12.8 dB（max |L| 0.199 → 0.229、15.3 → 16.7 kHz）。
